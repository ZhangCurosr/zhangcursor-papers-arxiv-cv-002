# 论文速读：TDFNet - 三投影可变形融合网络用于全景显著性检测

## 一句话总结
本文提出TDFNet，首个引入三投影（ERP、CMP、切线投影）可变形融合的全景显著性检测框架，通过跨投影可变形注意力与纬度引导融合机制，有效缓解球面-to-平面投影畸变，在四个PSOD基准上均达到SOTA。

## 研究问题与动机
- **ERP极区畸变问题**：等距柱状投影在极区存在严重拉伸，导致高纬度区域特征质量显著下降
- **CMP边界不连续**：立方体映射虽缓解极区变形，但引入立方体面边界的语义不连续性
- **现有双投影局限**：已有双投影方法（ERP+CMP）无法同时保持全局空间连续性与局部几何保真度
- **缺乏统一投影表示**：当前方法缺少能同时兼顾全局拓扑连续性、局部几何细节和精细边界信息的统一表征方案

## 核心贡献（创新点）
1. **首个三投影可变形融合框架**：引入切线投影作为第三分支，与ERP和CMP形成互补，同时保留全局结构连续性与低畸变局部几何细节；区别于以往仅用双投影的工作
2. **跨投影可变形注意力模块**：利用ERP与CMP的空间对应关系构建几何感知采样点，实现跨投影上下文聚合；与标准自注意力本质区别在于引入跨投影几何先验指导可变形采样
3. **纬度引导融合模块**：结合球面纬度先验与切线语义参考，自适应平衡ERP/CMP特征并实现跨投影对齐；区别于直接拼接或加权平均的融合策略
4. **端到端多投影协同建模**：首次在PSOD任务中系统整合三种投影表示，通过CDA和LGF实现三分支特征的深度融合与精炼

## 方法详解
**三分支编码器架构**：
- ERP分支：直接处理原始全景图像，使用Hybrid-ViT编码器提取全局连续特征
- CMP分支：将ERP转为6个立方体面，通过ResNet提取局部低畸变特征，再映射回ERP坐标域
- 切线投影分支：在4个纬度行分布18个切视点（3-6-6-3布局），每个FOV=80°，经ResNet18提取256维局部语义向量

**跨投影可变形注意力（CDA）**：
- 混合参考点生成：在ERP锚点基础上，沿8个方向（θ_m = πm/4）、4个径向层级（ρ_n = n/4）分布交叉投影参考点
- 可变形Transformer聚合：通过可学习偏移Δp和注意力权重A动态调整采样点，实现几何感知的跨投影特征增强
- 仅应用于ERP和CMP分支（切线视图无统一经纬坐标）

**纬度引导融合（LGF）**：
- 阶段一：ERP-CMP融合，提供两种策略：
  - Geometry Only：参数-free，W_geo = cos(M_lat × π/2)，赤道侧重ERP，极区侧重CMP
  - Mixed：轻量卷积子网络生成空间自适应权重，结合纬度先验与图像内容
- 阶段二：切线引导精炼，以融合特征为Query、18个切线视图为KV，计算跨投影注意力进行语义校准
- 残差融合系数：Geometry策略α=0.15固定，Mixed策略α=0.5σ(â)可学习

**解码器与损失函数**：
- ERP主解码器输出最终显著图P_final
- 立方体辅助解码器提供训练监督（推理时丢弃）
- 损失函数：L_structure = L_BCE^w + L_IoU^w，总损失L_total = L_ERP + L_Cube

## 实验与结果
**数据集**：
- 360-SOD（500张高分辨率全景图）
- 360-SSOD（1105张，10个语义类别）
- F-360iSOD（107张，1165个实例级标注）
- ODI-SOD（6263张，2K+分辨率）

**评估指标**：S-measure、MAE、F-measure、E-measure

**主要结果**：
- **360-SOD**：S_m=0.883, MAE=0.015, meF=0.835, maxF=0.847，较SCFA提升3.3%/2.8%，MAE降低16.7%
- **360-SSOD**：S_m=0.804, MAE=0.025, meF=0.697, maxF=0.708
- **ODI-SOD**：S_m=0.876, MAE=0.028, meF=0.833, maxF=0.845，较次优方法MAE降低20.0%，meF提升3.27%
- **F-360iSOD**：S_m=0.745, MAE=0.030, meE=0.762, meF=0.545，全面超越现有方法

**最强结果**：在ODI-SOD上全部6项指标达到最优，相比SIHE（次优）S_m提升3.0%，MAE降低22.2%

## 相关工作脉络
1. **2D SOD方法**：SENet、HVPNet、TP-Seg等基于CNN/Transformer的平面显著性检测，依赖透视投影假设，无法处理球面畸变
2. **全景显著性预测**：360-SOD提出者引入的等距偏置层、EPSNet的代理任务、图网络方法，但面向连续注视预测而非对象级分割
3. **ERP单投影方法**：DDS的自适应卷积核、DATFormer的畸变感知Transformer，仍无法补偿极区-赤道几何差异
4. **双投影方法**：CSMANet的通道-空间互注意力、HPNet的混合投影融合、SCFANet的ViT+CNN层次交互，受限于立方体边界不连续
5. **投影表示研究**：ERG/CMP的互补性已被认识，但切线投影在PSOD中尚未探索

## 局限性与未来方向
- 切线视图数量固定为18个，未探讨不同密度布局对性能的影响
- 模型仅训练于ERP输入，未验证直接处理原始球面数据的可能性
- 极端小样本或低对比度场景下的泛化能力未充分验证
- 切线分支使用冻结ResNet18，可能存在表征能力瓶颈
- 未测试跨域泛化（如从室内到室外场景迁移）

## 研究启发与可借鉴点
1. **三投影协同建模范式**：将ERP全局连续性、CMP局部保真度和切线视图无畸变特性结合的思路，可迁移至全景分割、全景深度估计等任务
2. **跨投影可变形注意力机制**：利用异构投影间的空间对应关系指导自适应采样，这一设计可推广至多视角/多模态特征对齐
3. **纬度先验引导的自适应融合**：将几何先验（纬度）作为融合权重构造依据，而非纯数据驱动，提升了模型可解释性和小样本稳定性
4. **切线视图作为语义校准信号**：离散无畸变局部视图为连续全局特征提供精细节点参考，类似思想可用于视频理解中的关键帧选择
5. **辅助解码器的训练策略**：立方体辅助解码器仅训练不推理的设计，可在多分支架构中推广以减少推理开销

## 关键术语表
**ERP（Equirectangular Projection）**：等距柱状投影，将球面展开为二维矩形，保持全局连续但极区严重拉伸
**CMP（Cube Map Projection）**：立方体映射，将球面分解为6个透视面，缓解极区变形但引入面边界不连续
**切线投影（Tangent Projection）**：将球面局部区域映射到相切平面，提供无畸变透视视图
**CDA（Cross-projection Deformable Attention）**：跨投影可变形注意力，利用异构投影间空间对应关系指导可变形特征采样
**LGF（Latitude-Guided Fusion）**：纬度引导融合，结合球面纬度先验和切线语义参考实现三投影特征自适应对齐
**S-measure**：结构相似度度量，评估预测图与真实掩码的结构一致性
**Hybrid-ViT**：混合ViT编码器，结合ResNet与Vision Transformer提取多尺度特征
