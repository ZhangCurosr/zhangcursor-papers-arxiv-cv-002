# 论文速读：Sterilizable-Scene-Graph-Generation-for-Operating-Rooms

## 一句话总结
本文提出了**SG-NCA**，首个基于神经细胞自动机（NCA）的手术场景图生成框架，通过类增量课程学习实现多类别分割，配合轻量化关系预测器，在白内障手术和胆囊切除术视频上达到与大型模型相当的精度，但参数量仅需其 **1/55**，可在无风扇边缘设备上运行，满足手术室卫生与隐私要求。

## 研究问题与动机
- **核心问题**：现有SOTA场景图生成模型依赖百万级参数的大模型，无法在手术室（OR）环境下部署。
- **卫生约束**：传统工作站带有风扇，无法有效灭菌，且会将灰尘扩散至手术室；无风扇密封设备更符合院感规范。
- **空间与连接限制**：大型工作站占用手术室宝贵空间，有线连接增加后勤复杂度。
- **数据隐私与延迟**：云端推理依赖稳定网络，存在延迟和数据主权风险；本地边缘计算可实现"隐私设计（privacy-by-design）"。
- **NCA的潜力未被探索**：NCA已被用于单解剖结构二值分割（MRI、X光、超声），但**从未用于多类别分割，更未用于结构化表示学习（如场景图）**。

## 核心贡献（创新点）
1. **首个NCA场景图生成算法**：将NCA从单类别/二值分割扩展到结构化表示学习（场景图），填补了NCA在多类别语义理解领域的空白。
2. **类增量课程学习训练策略**：提出渐进式类别注入方法，每次仅扩展少量隐藏维度并冻结旧参数，使NCA的多类别训练在计算上可行，避免了直接扩展维度导致的训练复杂度爆炸。
3. **端到端边缘部署验证**：首次在智能手机和Raspberry Pi等无风扇边缘设备上验证SG-NCA的实际部署可行性，证明其在能耗、温升和内存占用上完全满足手术室环境约束。

## 方法详解
- **分解建模**：将场景图生成分解为两个阶段：$p(G|I) = p(O|I) \cdot p(R|O, I)$，即先通过NCA分割得到对象节点，再预测对象间的关系边。
- **OctreeNCA分割 backbone**：采用八叉树数据结构，先将输入图像下采样至原始分辨率的 $1/2^5$，通过NCA扩散全局知识，再逐层上采样2×并与下一尺度的图像特征拼接，最终输出高分辨率分割掩码和多尺度特征。
- **分割接地特征提取（Segmentation-Grounded）**：对每个类别 $c$，根据其分割掩码 $M_c$ 对像素级特征进行平均池化，得到对象特征 $z_c$；通过投影矩阵将特征嵌入64维空间，再与过去7帧（1秒窗口）的缓存特征进行时序融合，最终投影为256维时序增强特征。
- **轻量关系预测器**：使用3层全连接网络 $g_\theta$，输入为对象特征对 $(z_i, z_j)$，输出语义关系类别（如 retracting、holding、inserting）；同时根据分割掩码的接触关系推断几何邻近关系（close to）。
- **类增量训练细节**：初始在5个最常见类别上训练；每引入一批新类别，隐藏状态维度 $C$ 增加 $C_+$，新增隐层维度 $H_+$；旧参数冻结，仅训练新增参数，大幅缩减反向传播的计算图规模。
- **阈值过滤**：分割掩码像素数大于阈值 $\tau = 150$ 时才作为有效对象节点加入图。

## 实验与结果
- **数据集**：Cholec80/CholecSeg-8k/CholecT50（胆囊切除术）、CATARACTS/CADIS/CAT-SG（白内障手术）；使用SASVi+SAM2生成的伪标签进行训练。
- **评估指标**：Dice score（分割）、Unconstrained Recall@K / mRecall@K / mAP@K（场景图，胆囊取K=4，白内障取K=6）。
- **分割结果**：SG-NCA在胆囊切除术上 macro Dice=70.9±16.4、micro Dice=76.6±21.9，参数量仅27,465；白内障上 macro Dice=75.0±15.9、micro Dice=82.1±18.0，参数量42,505。相比SegFormer（3.7M参数），参数量减少 **87倍**。
- **场景图生成**：SG-NCA的Recall/mRecall/mAP与所有基线（含SegFormer+MotifNet、UNet+MotifNet、SwinUNet+MotifNet）**性能相当**，参数量仅最轻量基线SegFormer的 **1/55**。
- **消融实验**：即使最小配置（$C_+=4, H_+=8$）也能保持合理分割性能，参数量进一步降至27,465（胆囊）/42,505（白内障）。
- **边缘部署**：SG-NCA在智能手机上内存仅44.25MB、温升0.66°K、功耗1.6W；Raspberry Pi温升0.62°K、功耗4.5W；工作站温升4.18°K、功耗223W。仅SG-NCA满足手术室热约束。
- **下游应用**：基于规则的场景图 Caption 生成展示了实际可用性。

## 相关工作脉络
1. **Med-NCA / M3D-NCA（Kalkhof et al., 2023）**：将NCA用于医学图像二值/3D分割，本文扩展NCA至多类别分割和结构化场景理解，是NCA能力的质变跃升。
2. **OctreeNCA（Lemke et al., 2025）**：提出基于八叉树的NCA实现高效分割，本文在此基础上进一步接入关系预测模块，实现从"像素级分割"到"图级理解"的跨越。
3. **Segmentation-Grounded SGG（Khandelwal et al., CVPR 2021）**：提出分割接地的场景图生成范式，本文首次将其与NCA结合，在参数量级上实现数量级压缩。
4. **MotifNet（Zellers et al., CVPR 2018）**：经典的关系预测基线，使用biLSTM编码对象间全局上下文；本文以3层全连接网络替代，参数量从MotifNet的数百万降至数千。
5. **S²former-OR / Oracle（Pei et al., 2024; Özsoy et al., 2024）**：基于Vision Transformer和VLM的大参数量场景图方法，本文与其定位根本不同——追求边缘可部署而非SOTA精度。

## 局限性与未来方向
- **类别数量受限**：NCA隐层维度上限决定了可分割类别数，当前方法需课程学习逐步扩展，尚未验证大规模类别（>20类）的扩展性。
- **关系类型有限**：仅预测静态语义关系（retracting/holding/inserting等），未建模时间维度上的动作流和手术阶段演变。
- **依赖伪标签训练**：由于真实分割标注稀缺，训练大量依赖SASVi+SAM2生成的伪标签，可能引入系统性偏差。
- **未涉及复杂遮挡与形变**：NCA基于局部邻域扩散，对强遮挡、器械大幅形变场景的分割鲁棒性有待验证。
- **缺少临床前瞻性试验**：目前仅在离线视频上评估，未在真实手术环境中进行实时性、可靠性和临床效用验证。

## 研究启发与可借鉴点
1. **课程学习的参数冻结策略**：类增量训练中冻结旧参数、仅训练新增参数的设计，可迁移至任何需要逐步扩展模型容量的NCA或 cellular automaton 变体任务。
2. **分割接地特征提取范式**：将像素级特征通过掩码池化聚合为对象级特征，再进行时序融合，是一种高效且参数友好的特征构建方式，可复用于其他边缘端视觉理解任务。
3. **边缘部署驱动的模型设计**：以"无风扇设备可用"为硬性约束反向指导模型架构选型（轻量NCA+薄关系头），为医疗AI的"部署优先"设计提供了可量化的评估范式（内存/温升/功耗三指标）。
4. **NCA用于多类别分割的扩展路径**：本文证明NCA可通过课程学习突破单类别限制，这一思路可探索至病理切片多组织分割、内窥镜多器官分割等场景。
5. **结构化表示学习的极简实现**：证明场景图生成不一定需要VLM或大Transformer，结合高效的局部扩散模型+薄预测头即可达到可用性能，为资源受限场景的表征学习提供新方向。

## 关键术语表
- **Neural Cellular Automaton (NCA)**：受细胞自动机启发的轻量级神经网络，通过学习局部邻域更新规则实现像素级分类和特征传播。
- **OctreeNCA**：将图像嵌入八叉树数据结构的多尺度NCA，在粗粒度尺度扩散全局知识、在细粒度尺度实现精确分割。
- **Segmentation-Grounded Scene Graph**：以分割掩码为基础提取对象特征并构建场景图的生成范式，避免独立的目标检测模块。
- **Class-Incremental Curriculum Learning**：逐步引入新类别的训练策略，每次扩展隐层维度并冻结已有参数，降低多类别NCA的训练复杂度。
- **Recall@K / mRecall@K / mAP@K**：场景图生成的标准评估指标，分别衡量关系预测的召回率和平均精度，K为每帧允许预测的最大关系数。
- **Privacy-by-Design**：将数据隐私保护内嵌于系统架构设计中，本工作中指推理全程在本地边缘设备完成，无需上传云端。
- **Action Triplet**：形如 (instrument, action, tissue) 的手术动作三元组，是手术场景图中关系边的语义标签。
- **SASVi**：基于SAM2增强的自动化提示网络，用于从无标注手术视频中生成伪分割标签。
