# 论文速读：Question-Guided-Evidence-Acquisition-for-Multimodal-Visual-Q

## 一句话总结
提出 **Q-Guide**，一种问题驱动的主动证据采集智能体框架。该方法将文档视觉问答的感知从单次快速编码改为多轮迭代式“慢思考”，让模型根据问题按需调用针对性感知工具（文本提取、局部放大、结构化布局重建等），在积累足够证据后才提交答案，从而在 DocVQA2026 与漫画跨页命名任务上显著超越直接提示与复杂编排基线。

## 研究问题与动机
- **感知与推理的脱节**：现代 MLLM 能“看到”文档，但在处理小字、密集表格、颜色高亮与拓扑元素时仍不可靠；常见失败模式是推理能力充足，却未能准确提取问题所依赖的具体证据。
- **固定感知的局限性**：现有文档 VQA 系统通常对页面执行一次快速编码（System-1），无论问题类型如何均以相同方式处理，导致关键证据被淹没在均匀表征中。
- **编排复杂度收益见顶**：近期 Agentic VQA 工作倾向堆叠规划器、路由器与多智能体协作，但实际引入 brittle 中间决策、噪声摘要与上下文干扰，并未带来预期增益。
- **慢思考应作用于感知**：作者主张将测试时额外算力优先分配给“决定接下来该看什么”，而非仅在语言推理层做 Chain-of-Thought，从而实现问题条件化的主动感知恢复。

## 核心贡献（创新点）
- **将文档 VQA 重新定义为测试时感知推理**：以问题条件驱动的迭代感知循环替代固定单遍编码，证明“感知预算”可控的慢思考能突破 System-1 上限。
- **提出紧凑单智能体架构 Q-Guide**：仅用一个 MLLM 策略 + 五种针对性恢复工具 + 置信度门控即可完成证据采集与终止判断，无需额外规划器或 Critic 网络。
- **实证感知导向优于编排复杂度**：消融表明添加三阶段规划、类别路由或多智能体协作不仅无益，反而降低性能；核心增益来自定向工具调用而非控制逻辑堆叠。
- **跨域泛化与底座无关性**：同一设计无需结构修改即可迁移至漫画跨页命名任务，且在 Claude Opus 4.6 / Sonnet 4.6 / Opus 4.5 三个商业底座上均稳定领先。

## 方法详解
- **问题建模**：问答过程形式化为证据状态迭代 $e_t = (q, \mathcal{D}, O_t)$，其中 $O_t$ 为已收集观测序列，每个观测 $o_i=(a_i, r_i, y_i)$ 记录工具类型、归一化区域坐标与返回内容。
- **五类感知恢复工具**：
  1. **Text elements recovery**：文本检测、阅读顺序恢复与识别，适用于小字/分散标签/表单字段。
  2. **Visual details recovery**：高分辨率裁剪（不做 OCR），让 LLM 直接观察颜色、形状、相对位置与图表细节。
  3. **Targeted lookup**：对已定位区域发起自然语言提问，返回短答案与置信度，适用于表格单元格/数值/标签提取。
  4. **Spatial elements recovery**：词级定位、颜色分布、沿几何路径文本回收，适用于高亮值/地图拓扑/路径排布。
  5. **Structure layout recovery**：表格/表单/层级结构解析，并关联单元格视觉属性（文字颜色/背景色）。
- **置信度门控与终止策略**：模型提交时输出 $\sigma \in \{\text{LOW, MED, HIGH}\}$，系统基于实测可靠性 $\rho(\ell)$ 设定阈值 $\tau$（默认 MED）。若充分性谓词 $\phi(e_t)=1$ 则提交；若 $\phi=0$ 且 $t \ge T_{\max}$ 则强制返回 Unknown；低于阈值的提交会触发轻量验证，要求答案必须在 $O_t$ 中有显式支撑，否则回退到 Unknown。
- **长文档分块融合**：采用重叠窗口分块，每块独立运行 Q-Guide 循环，最终以置信度加权多数投票（权重 LOW:1, MED:2, HIGH:3）融合，优于逐页检索。
- **复杂度控制**：总 token 消耗近似为 $\alpha P_{\mathrm{ctx}} + \beta \sum |y_i| + \gamma T$，与文档总页数 $N$ 无关；实测 Q-Guide 93% 的 token 用于输入侧证据恢复，输出侧生成开销极小。

## 实验与结果
- **数据集**：DocVQA2026（80 题，8 类文档：商务报告、漫画、工程图纸、信息图、地图、科学论文、海报、幻灯片，单文档最长 181 页）与自建 **M109NC**（基于 Manga109-v2026 的跨页角色命名，1500 样本）。
- **基线**：Direct Prompting（Visual / OCR / Visual+OCR）、Agentic（ARIAL、DocAgent、MDocAgent），所有基线均在同一 Claude 底座上重跑以隔离策略差异。
- **DocVQA2026**：Q-Guide 达 **65.0%**，较最强直接提示（Visual+OCR Prompt, 38.8%）提升 **+26.2pp**，较最强 Agentic 基线（DocAgent/MDocAgent, 40.0%）提升 **+25.0pp**；工程图纸与科学海报类别达 90.0%。
- **M109NC**：Claude-OCR 下 **32.4%**（+8.0pp vs DocAgent），GT-OCR 下 **53.7%**（+28.8pp vs GT-OCR Visual+OCR）。
- **关键规律**：
  - 准确率随感知预算单调递增，$T_{\max}=1 \to 40.0\%$，$T_{\max}=2 \to 55.0\%$，$T_{\max}\ge3 \to \sim65\%$；饱和拟合 $R^2=0.982$，90% 增益在 $t^\star\approx3.2$ 轮内实现。
  - 工具重要性：移除 Visual Inspection（-17.2pp）或 Targeted Query（-16.2pp）降幅最大；两者组合移除导致 -33.4pp，超过整体基线提升，印证问题条件化提取是核心驱动力。
  - 错误分解（M109NC）：64.5% 为感知匹配错误，32.0% 为主动拒答，仅 3.5% 为对话共指错误，再次确认瓶颈在感知而非语言推理。

## 相关工作脉络
- **OCR-free / 文档专用 MLLM**（如 PaddleOCR-VL、mplug-docowl2、TextMonkey）：侧重模型端架构与训练数据改进；Q-Guide 走系统端路线，保留通用 MLLM，通过外部工具按需补充感知。
- **Tool-augmented / Agentic VQA**（如 ARIAL、AgenticOCR、TextCoT）：强调迭代证据收集；Q-Guide 进一步追问“问题条件驱动的工具哪些真正有效”，避免无效调用与开销叠加。
- **多智能体文档 QA 编排**（如 DocAgent、MDocAgent、M3DocRAG）：依赖规划器、多角色协作与检索模块；本文证明复杂控制逻辑引入脆弱性，紧凑单环设计在相同底座上收益更高。
- **慢思考 / 测试时计算**（如 CoT、Visual Sketchpad）：传统路径将额外算力用于语言推理链；本文首次将“慢思考”明确作用于**感知决策本身**。
- **漫画多任务理解**（如 CoMiX、VDocRAG）：本文构建的 M109NC 填补了跨页角色命名 benchmarks 空白，验证框架在非文档视觉域的零样本迁移性。

## 局限性与未来方向
- **地图类任务存在结构瓶颈**：当前工具擅长局部文本与细节恢复，但无法将地图建模为可导航的拓扑图，缺乏专用 map-to-graph 工具与拓扑误差度量。
- **对 OCR 质量敏感**：M109NC 上 Claude-OCR 与 GT-OCR 差距达 21.3pp，表明残差误差主要来自文本提取质量而非推理架构本身。
- **跨页视觉匹配仍依赖隐式相似度**：角色身份判定由 LLM 原生评估，未引入显式人脸/帧特征嵌入匹配器，存在可优化的判别基线。
- **长文档分块策略较粗糙**：当前使用固定窗口重叠分块 + 置信度投票，尚未引入问题感知的检索器或概率多块证据模型。
- **未来方向**：开发专用拓扑感知工具、引入开放权重底座适配、构建问题感知的多块证据概率融合模型。

## 研究启发与可借鉴点
- **“感知慢思考”范式**：为视觉理解任务提供清晰的算力投放策略——优先用测试时计算解决“看哪里”，而非“想多深”，可有效突破单次前向传播的性能天花板。
- **置信度门控的工程优雅性**：用实测可靠性 $\rho(\ell)$ 校准模型自报置信度，替代启发式阈值或额外 Critic 网络，易于部署且避免过拟合单一指标。
- **工具组合的优先级启示**：Visual Inspection 与 Targeted Query 贡献最大，提示后续研究应优先打磨
