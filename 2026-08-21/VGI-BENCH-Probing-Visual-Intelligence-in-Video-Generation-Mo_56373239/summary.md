# 论文速读：VGI-BENCH: Probing Visual Intelligence in Video Generation Models

## 一句话总结
本文提出 VGI-BENCH，一个面向视频生成模型视觉推理能力的过程敏感型评估基准（27任务/810实例），采用真实风格输入与多级难度校准；评测显示当前最强模型 Seedance 2.0 仅获 51.0% 的综合分，揭示模型在物理连贯性、规则遵守与状态追踪上仍存在显著瓶颈，且去噪后期几乎不具备自我修正能力。

## 研究问题与动机
- **核心问题**：当前视频生成模型是否具备可被可靠评估的零样本视觉推理能力？其推理行为在哪些维度失败、为何失败？
- **输入风格失配**：现有基准多采用线稿/抽象图以提升可控性，但与视频模型的现实图像先验存在分布偏移，导致性能下降更多反映视觉域不匹配而非真正推理缺陷。
- **缺乏过程敏感性**：多数任务仅需从输入直接推断最终答案，未强制模型通过连续状态演化（visual rollout）求解，无法检验“逐步推演+落地到生成轨迹”的核心能力。
- **难度失控**：部分任务超出当前模型可行范围（如超长时域、依赖医学等专业知识），失败缺乏诊断价值；需在校验可行性边界内设置梯度难度。

## 核心贡献（创新点）
1. **提出 VGI-BENCH 双层级分类基准**：按视觉特征划分 4 个互斥任务域（Visual Organization / Physical Manipulation / Structured Puzzles / Spatiotemporal Dynamics），并为每个任务标注 1~3 个可重叠技能标签（共 7 类），实现粗粒度域诊断与细粒度能力拆解。
2. **设计过程敏感的双指标评估框架**：全局完成度（Completeness）与局部规则合规性（Rubric Score）相乘得到最终分，从根本上防止“结果看似正确但过程违规”或“过程保守但零进展”的评分偏差。
3. **提供多维度诊断分析**：从输出失败模式、输入条件敏感性、合成数据微调迁移边界、内部去噪动力学四个互补视角揭示当前模型视觉推理的行为机制与瓶颈。
4. **构建高可靠 VLM-as-Judge 评估器**：基于 Gemini-3-Flash 实现自适应粗→细帧采样与滑动焦点窗口，与人工偏好的 AUC 达 0.803，验证了自动化过程评测的可行性。

## 方法详解
- **任务格式**：统一 I/O 流程，模型接收文本提示 + 首帧图像，生成 5~10 秒视频完成指定视觉程序；严格禁止短路捷径（如瞬移、穿墙、直接篡改场景）。
- **输入构建**：图像来自公开数据集或 GPT-Image-2 / Nano Banana Pro 生成，经人工在环审核剔除伪影与布局偏差，统一 16:9 比例；Prompt 包含任务目标、对象/属性约束、允许与禁止动作、背景与相机固定要求。
- **难度校准**：预生成过滤阶段对每个任务采样 Easy 级实例在 Sora2 / Veo3.1 / Kling3.0 等 SOTA 模型上测试，仅保留“至少 1 个模型能解、至少 1 个失败”的任务；随后人工二次审核目标忠实度与时长。
- **评估指标设计**：
  - **Completeness (Comp.)**：2fps 均匀采样，VLM 对照三级标准（<complete>/<partial>/<failed>）映射为 {1, 0.5, 0}。
  - **Rubric Score (Rub.)**：针对每任务定制 checklist，采用 4fps 初筛 + 可疑区间 8fps 精评的自适应采样，配合 10 帧滑动窗口（重叠 1 帧）；每项违规次数 $x$ 得分 $1/(x+1)$，Rub 为所有项均值。
  - **Final Score** = Comp. × Rub.，乘法聚合迫使目标达成与过程合规互为必要条件。
- **评估器实现**：三阶段 VLM 调用（Completeness pass → Rubric pass → Polish call 去重聚合），Polish call 无图仅基于前两轮评论文本执行跨窗口合并与违规计数。

## 实验与结果
- **评测范围**：9 个视频生成模型（Seedance 2.0 / Sora 2 / Veo 3.1 / Kling 3.0 / Wan 2.7 / Gen 4.5 / MiniMax-H3 / HunyuanVideo-1.5 / Wan 2.2-I2V）及 11 个图像模型（适配子集）。
- **核心数字**：
  - 最强模型 **Seedance 2.0 综合分 51.0%**，开源最高 MiniMax-H3 44.4%，整体远未解决。
  - 严格成功率（Comp=1 且 Rub=1）Human ceiling 约 97.1%，模型最高仅 14.0%。
  - Structured Puzzles 域最难；**Topology** 与 **Temporal** 为最弱技能维度。
  - 图像模型在静态目标子集上平均 55.0%（Nano Banana Pro），但仍仅测试目标状态推断，不含过程约束。
- **评估器可靠性**：完整方案 AUC 0.803 / Pairwise Acc 73.2%；移除自适应 fps（↓至 0.772）或焦点窗口（↓至 0.753）均显著降低与人工一致性。
- **关键分析结论**：
  - 失败主因：物理坍塌（物体穿透/悬浮）、规则违反（越界/跳步）、对象/状态不一致（凭空出现/重置）。
  - 输入敏感性：线稿输入显著拉低开源模型表现，证实抽象输入会混淆域偏移与推理评估。
  - 合成微调迁移：VBVR-Wan2.2 在 Overlap 任务提升 +40.5，Non-overlap 仅 +6.2，说明迁移上限由训练分布的结构覆盖决定。
  - 去噪动力学：wrong→correct 自我修正率全程 <1%，后期步骤稳定率升至 90.6%，表明模型主要“锁定并细化早期假设”而非纠错。

## 相关工作脉络
- **TiVi-Bench / V-ReasonBench / VBVR-Bench**：均为视频推理评测，但依赖脚本/抽象输入或无难度校准；VGI-BENCH 以真实风格输入+过程敏感+难度分级实现更贴近当前模型能力边界的诊断。
- **PhysGenBench / WorldSimBench**：聚焦物理仿真与场景演化，推理密度较低；VGI-BENCH 针对明确规则约束的多步逻辑与状态追踪任务。
- **MMGR / MORSE-500**：前者偏多模态生成推理，后者高度程序化可控；VGI-BENCH 在保持可控性的同时引入自然图像先验与细粒度 rubric 检查。
- **VBVR-LORA 微调工作**：展示大规模合成数据可提升特定结构任务；本文通过 Overlap/Semi-overlap/Non-overlap 分组量化其迁移边界，指出非重叠技能仍难提升甚至退化。
- **dLLM / 扩散链式思考研究**：提出去噪迭代可类比思维链；本文通过解码中间状态并构建转移矩阵，实证指出当前视频模型缺乏实质自我修正能力。

## 局限性与未来方向
- **局限**：任务时长限制在 5~10s，无法评估长程多步规划；仅覆盖 I2V 固定 16:9，未涉及 T2V、多图条件与音频驱动；全英文提示/rubric，无多语言评估；任务集为代表性抽样而非穷举。
- **未来方向**：扩展至长时域与多模态条件；支持多语言与跨语言视觉推理；探索突破合成数据迁移瓶颈的 Scaling 策略；研究如何激发模型内在的自我修正与状态回溯机制。

## 研究启发与可借鉴点
1. **Comp×Rub 乘法聚合范式**可迁移至任何需验证中间轨迹的生成评测（如机器人策略、代码生成、具身规划），有效分离“目标正确性”与“过程合规性”。
2. **输入风格对齐是基准效度的前提**：本文用对照实验证明抽象输入会掩盖真实推理差距，未来构建生成模型评测时应优先对齐模型预训练分布的自然风格。
3. **去噪轨迹状态转移矩阵**提供了一种量化“模型思考过程”的工具，可直接复用于 dLLM 或视频模型的内部机制诊断，区分“规划滞后”与“执行退化”。
4. **Overlap/Semi-overlap/Non-overlap 分组评估微调迁移**的设计，为合成数据构建、课程学习与领域自适应提供了可操作的度量框架。
5. **Oracle Prompting 作为能力上限探针**：即使给定完整解法，模型仍难以渲染合法轨迹，说明当前瓶颈主要在执行而非规划，该设计可作为 test-time scaling 策略的有效对照基线。

## 关键术语表
- **VGI-BENCH**：面向视频生成模型的视觉推理评估基准，含 27 任务/810 实例，采用双层级分类与过程敏感评估。
- **Completeness (Comp.)**：衡量视频全局进展是否达成任务目标的三级度量（complete/partial/failed）。
- **Rubric Score (Rub.)**：基于细粒度规则 checkilist 的局部过程有效性度量，采用逆衰减惩罚与自适应帧采样。
- **Self-correction**：生成模型在去噪后期将错误中间状态修正为正确状态的能力，本文发现当前模型该能力近乎缺失。
- **Process-sensitive**：任务成功不仅依赖最终状态，还要求中间演化轨迹严格符合物理/逻辑规则。
- **Oracle Prompting**：在提示中显式提供完整解题步骤，用于探测模型指令遵循与过程渲染的能力上限。
- **dLLM**：Diffusion Large Language Model，将扩散去噪迭代与链式思考推理相联系的新型建模范式。
