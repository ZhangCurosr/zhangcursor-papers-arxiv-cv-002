# 论文速读：Question-Guided-Evidence-Acquisition-for-Multimodal-Visual-Q

## 一句话总结
本文提出 Q-Guide，一种面向文档视觉问答（Document VQA）的紧凑智能体框架，通过将感知过程变为问题条件驱动的主动循环（"慢思考"感知），显著优于单次推理和更复杂的多智能体编排方案。在 DocVQA2026 上达到 65.0% 准确率，较最强基线提升 25–26 个百分点，且在三个 Claude 骨干模型上泛化一致。

## 研究问题与动机
1. **核心痛点**：多模态大语言模型（MLLM）虽能将文档页面纳入上下文，但在可靠"读取"小文字、表格、颜色标记和拓扑结构方面仍存在显著缺陷——模型推理能力强，但未能可靠感知问题所需的具体证据。
2. **现有方法的不足**：多数文档 VQA 系统采用单次快速感知（System-1），无论问题类型如何都以固定方式编码整页文档，导致对视觉密集型内容的感知存在盲区。
3. **编排复杂度的陷阱**：近期的 agentic 方法（如规划智能体、多智能体协作、路由模块）试图通过更复杂的控制逻辑提升性能，但更重的编排引入了规划错误、冗余反思和上下文噪声等新失败模式。
4. **研究动机**：将测试时计算预算从"语言级慢思考"转向"感知级慢思考"，让模型在回答前主动决定"下一步该看哪里"，以问题驱动的感知恢复替代固定的单次编码。

## 核心贡献（创新点）
1. **将文档 VQA 形式化为测试时感知推理问题**：提出一个精简的单循环智能体 Q-Guide，通过问题条件驱动的感知预算迭代，证明提升感知定向比加重编排逻辑更有效；准确率随感知轮次（T）扩展，在约 2–3 轮后饱和。
2. **跨域通用性验证**：同一框架无需结构调整即可迁移到漫画（Manga109）和工程图纸等视觉差异极大的领域，且在不同模型架构间保持一致提升。
3. **模型无关性与消融验证**：在 Claude Opus 4.6、Sonnet 4.6 和 Opus 4.5 三个不同骨干模型上均获得显著提升；消融实验表明加规划器、路由器或多智能体协作无益甚至有害，证明增益来自感知定向而非控制复杂度。

## 方法详解

### 问题形式化
定义文档 $\mathcal{D} = \{p_1, ..., p_N\}$ 和用户问题 $q$，Q-Guide 通过迭代收集证据并在证据不足时返回 Unknown。引入四元组 $(\mathcal{E}, \mathcal{A}, \mathcal{T}, \phi)$：
- **证据状态**：$e_t = (q, \mathcal{D}, O_t)$，其中 $O_t = (o_1, ..., o_{k_t})$ 为已收集的观察序列，每条观察 $o_i = (a_i, r_i, y_i)$ 记录工具、归一化区域和返回内容，确保每个答案都可追溯到页面位置。
- **动作空间**：$\mathcal{A} = \mathcal{A}_{tool} \cup \{\text{submit}\}$，含五个感知恢复工具和提交动作。
- **状态转移**：$e_{t+1} = \mathcal{T}(e_t, \mathbf{a}_t)$，工具执行后追加观察到证据状态。

### 充分性与终止机制
引入置信度阈值门控 $\phi$：模型自报告置信度 $\sigma(e_t) \in \{\text{LOW, MED, HIGH}\}$，通过经验校准可靠性 $\rho(\ell)$ 确定阈值 $\tau = \text{MED}$。当 $\phi(e_t)=1$ 时提交答案；当 $\phi(e_t)=0$ 且达到最大轮次 $T_{max}$ 时提交 Unknown；否则继续收集。阈值的经验依据：HIGH 置信度答案的可靠性约为 MED 的 1.6 倍。

### 五类问题驱动恢复工具
1. **文本恢复（Text Recovery）**：从选定区域检测、识别文本，处理小文字、尺寸标注、表格单元等。
2. **视觉细节恢复（Visual Inspection）**：返回高分辨率裁剪图，不做 OCR 而是让 LLM 直接看清颜色、形状、布局等细节。
3. **目标查询（Targeted Query）**：对已定位区域进行自然语言问答，返回精确值及置信度。
4. **空间元素恢复（Spatial Recovery）**：提供文本和视觉元素的坐标锚定，适用于地图、路径排列等拓扑结构。
5. **结构布局恢复（Structure Recovery）**：提取表格、表单和层级结构，并关联单元格的视觉属性（颜色、背景色）。

### 长文档处理
采用重叠分块策略 + 置信度加权裁决：$\hat{a} = \arg\max_v \sum_{j:a_j=v} w(\sigma_j)$，权重 LOW:1, MED:2, HIGH:3。比页级检索更有效（65.0% vs 50.0%）。

### 计算复杂度
总成本线性于轮次 $T$ 和累积证据量，与文档长度 $N$ 无关，因为仅编码 $P_{ctx} \ll N$ 页到上下文。Token 消耗近似为 $\alpha P_{ctx} + \beta\sum|y_i| + \gamma T$。

## 实验与结果

### 数据集
- **DocVQA2026**：80 个问题覆盖 8 类文档（商业报告、漫画、工程图纸、信息图、地图、科学论文、科学海报、幻灯片），文档页数 1–181，侧重感知广度。
- **M109NC（Manga109 Character Naming）**：从 Manga109 构建的角色命名任务，约 1500 个样本，测试跨页身份匹配和日语对话理解，侧重深度单一任务。

### 评估基线
直接提示：Visual Prompt、OCR Prompt、Visual+OCR Prompt
智能体基线：ARIAL、DocAgent、MDocAgent

### 主要结果
- **DocVQA2026**：Q-Guide 达 65.0%，较最强直接基线（Visual+OCR 38.8%）提升 26.2pp，较最强智能体基线（DocAgent/MDocAgent 40.0%）提升 25.0pp。工程图纸和科学海报类别达 90.0%。
- **M109NC**：Q-Guide 达 32.4%（Claude OCR）/ 53.7%（GT OCR），较最强智能体基线（MDocAgent 25.6%）提升 6.8–28.8pp。

### 消融实验
- **编排策略**：直接提示 27.5–38.8% → 双阶段提取-综合 44.3% → 基本智能体 50.0% → Q-Guide 65.0%。3 阶段研究和路由策略反而低于基线（35.7% vs 44.3%）。
- **工具重要性**：移除 Visual Inspection (-17.2pp) 和 Targeted Query (-16.2pp) 影响最大；两者组合移除导致 -33.4pp，超过 Q-Guide 总提升幅度。
- **轮次预算**：$T=1$ 时 40.0%，$T=2$ 时 55.0%，$T\geq3$ 时约 65%，饱和曲线拟合 $R^2=0.982$，90% 增益在 $t^*\approx3.2$ 轮内实现。
- **模型泛化**：在 Opus 4.6/Sonnet 4.6/Opus 4.5 上均保持最佳性能；MDocAgent 在弱模型上下降（40.0%→31.4%），而 Q-Guide 鲁棒。

## 相关工作脉络
1. **OCR-free 文档专用 MLLM**（Qwen2.5-VL、TextMonkey、PaddleOCR-VL）：从模型侧改进文本密集文档的表示能力；Q-Guide 走系统侧路线，保持通用 MLLM 不变，暴露问题驱动的感知恢复工具。
2. **工具增强型 VQA**（ToolVQA、Chain-of-Spot）：让视觉语言模型调用外部感知模块迭代收集信息；Q-Guide 与之共享动机，但更聚焦于哪种感知恢复动作在问题条件下真正有效。
3. **智能体编排文档 QA**（DocAgent、MDocAgent、ARIAL、AgenticOCR）：探索规划智能体、多智能体协作、检索模块和迭代自我修正；Q-Guide 对比实验证明更重编排引入的中间错误可能抵消收益。
4. **视觉链式思维**（Visual Sketchpad、CoT-of-Visual-Thought）：通过可视化中间步骤增强推理；Q-Guide 的感知恢复循环在结构上类似，但专注于"看哪里"而非"如何推理"。
5. **文档检索增强生成**（M3DocRAG、VisRAG、VDocRAG）：通过检索相关片段辅助生成；Q-Guide 的分块裁决更轻量，且目标不是检索而是主动感知。

## 局限性与未来方向
1. **地图类问题仍是主要短板**：当前工具恢复局部文本和细节，但无法将地图表示为可导航结构，缺乏专用的 map-to-graph 工具。
2. **OCR 质量敏感**：M109NC 上 Claude OCR 与 GT OCR 差距达 21.3pp，说明文本恢复质量仍是瓶颈，但即使低质量 OCR 下也优于所有基线。
3. **长文档聚合仍依赖简单分块**：当前重叠分块策略有效，但缺乏问题感知的页面选择机制。
4. **跨页身份匹配的显式化**：当前通过隐式加权相似度进行角色匹配，可考虑引入显式嵌入距离匹配器作为自然基线。
5. **向开放权重骨干模型的迁移**：目前是 Claude 封闭模型，未来需验证在开源多模态模型上的效果。

## 研究启发与可借鉴点
1. **"慢思考"应用于感知而非语言**：将测试时计算预算从语言推理转向主动感知，为其他视觉任务（如工业检测、医学影像分析）中的感知不足问题提供了新思路。
2. **置信度门控的经验校准机制**：通过测量 $\rho(\ell)=Pr[\text{correct}|\sigma=\ell]$ 而非信任标签本身来确定阈值，为智能体中的自评估提供了可复用的校准范式。
3. **工具重要性解耦分析**：通过 leave-one-out 证明"视觉检查+目标查询"是核心贡献，指导未来系统设计的投入优先级。
4. **简单循环优于复杂编排**：消融结果强烈支持精简设计，提醒团队在面对复杂问题时优先验证核心机制而非堆叠模块。
5. **长文档的置信度加权裁决**：重叠分块 + 置信度投票策略比页级检索更有效，可在多文档场景下迁移使用。

## 关键术语表
- **Test-time compute（测试时计算）**：在推理阶段而非训练阶段分配的额外计算预算，用于"慢思考"决策或感知恢复。
- **Evidence state（证据状态）**：智能体在每一轮累积的认知状态，包含问题、文档和已收集的观察序列。
- **Sufficiency predicate（充分性判定）**：判断当前证据是否足以回答问题的二值函数，由模型自报告置信度和校准阈值共同决定。
- **Question-conditioned perception（问题条件感知）**：根据具体问题动态选择感知目标和工具的策略，替代固定的单次文档编码。
- **Perception budget（感知预算）**：智能体允许的最大迭代轮次 $T_{max}$，控制计算开销与性能之间的权衡。
- **Reliability calibration（可靠性校准）**：测量自报告置信度与实际准确率之间的映射关系，用于建立可信的终止阈值。
