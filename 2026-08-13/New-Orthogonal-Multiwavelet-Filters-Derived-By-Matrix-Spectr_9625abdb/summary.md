# 论文速读：New-Orthogonal-Multiwavelet-Filters-Derived-By-Matrix-Spectr

## 一句话总结
本文基于矩阵谱理论构造了新型正交多小波滤波器 New1 与 New2，系统评估其在图像压缩与信号/图像去噪任务中的性能，揭示出新滤波器在低压缩比与一维去噪中的显著优势，同时明确其在高压缩比与深层分解下的稳定性短板。

## 研究问题与动机
- 传统正交多小波（GHM、SA4CL、Alpert 等）在高压缩比或深层分解时容易出现性能急剧劣化，难以兼顾能量集中能力与数值稳定性。
- 现有滤波器设计多依赖经典代数构造，缺乏基于矩阵谱的系统化优化路径，导致在不同任务（压缩 vs 去噪）间泛化能力有限。
- 亟需一套统一、多维的评测协议，覆盖多种标准测试图像与 1D 信号、多压缩比与噪声方差、软/硬阈值策略，以客观厘清新旧滤波器的适用边界。

## 核心贡献（创新点）
1. 提出 New1 与 New2 两种正交多小波滤波器，通过矩阵谱方法推导构造系数，旨在提升时频局部化与能量压缩效率。
2. 构建了覆盖 Brick Wall、Texture 5、Subwater、House、Kiel 及三种经典 1D 信号的综合基准，统一报告 MSE、PSNR、SSIM、MS-SSIM 四项指标。
3. 量化揭示了 New1 在低压缩比（≤16:1）与 1D 去噪任务中的领先优势，同时明确指出其深层分解下数值稳定性不足的 trade-off，为工程选型提供清晰决策依据。
4. 系统对比 Soft/Hard 阈值与分解层级的耦合效应，证明最优层级并非固定值，而随滤波器类型与噪声强度动态变化。

## 方法详解
- **滤波器构造**：基于矩阵谱理论推导正交多小波滤波器系数（具体谱分解推导见原文前置部分，本节以实验验证为主）。
- **图像压缩流程**：对测试图像执行 1–7 层正交多小波变换，经量化与编码达成目标压缩比（CR = 4:1、8:1、16:1、32:1、64:1）。
- **去噪流程**：叠加 AWGN（σ = 10、15、20），对分解系数分别施加 Soft Threshold 与 Hard Threshold，再通过逆变换重构信号/图像。
- **评估体系**：同时输出 MSE、PSNR（dB）、SSIM 与 MS-SSIM，兼顾保真度与感知质量；分解层级 L 在压缩任务中遍历 1–7，在去噪任务中固定 L=5（部分对比至 L=1–5）。
- **控制变量**：保持阈值策略、噪声模型与基线滤波器的一致性，确保不同多小波间的公平对比。

## 实验与结果
- **图像压缩**：
  - **Brick Wall**：New1 在 CR=16:1 取得 PSNR=28.03 / SSIM=0.9845，优于 GHM(26.87) 与 SA4(27.90)；CR=32:1 时 New1(26.62) 仍领先 GHM(25.24)，Alpert 骤降至 20.82；CR=64:1 下 Alpert L7 仅 20.50，New1 保持 25.19。
  - **Texture 5**：New1 在 CR=4:1 表现极佳（PSNR=42.51 / SSIM=0.9900），远超 GHM(36.03/0.9617)；但 CR=32:1 时 New1 跌至 15.74，GHM 仍稳健维持 25.01。
  - **Subwater**：New1 在 8:1、16:1、32:1 均保持最优或接近最优（8:1 时 PSNR=33.13）。
- **1D 信号去噪**：New1 在所有信号及 σ=10、15 条件下均取得最低误差 ε（Piece-Polynomial: 26.32/31.80；Cusp: 0.0495/0.0534；HeaviSine: 0.4250/0.6944），Integer Haar 次优，Alpert 系统性最差（Piece-Polynomial ε=69.66/74.91）。
- **图像去噪（House, σ²=20）**：
  - **Soft 阈值**：SA4CL 在 L2 达 PSNR=28.70 / SSIM=0.7887，New2 在 L3 达 PSNR=28.79；New1 随层级加深性能崩塌（L5 仅 PSNR=22.28 / MSE=384.37）。
  - **Hard 阈值**：SA4CL 与 GHM 在 L2–L4 表现稳健，New1 同样呈现深层不稳定（原始表格数据截断，可复现部分以原文 Table 19 为准）。
- **核心结论**：New1 在低压缩比与 1D 去噪中优势显著，但深层分解下数值稳定性差；GHM/SA4CL 在高压缩比与深层级更鲁棒；Alpert 整体表现最弱且对高分辨率/深分解极度敏感。
