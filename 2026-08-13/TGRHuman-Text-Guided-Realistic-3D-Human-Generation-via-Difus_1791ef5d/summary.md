# 论文速读：TGRHuman: Text-Guided Realistic 3D Human Generation via Diffusion Renderer

## 一句话总结
本文提出 TGRHuman，通过解耦几何与纹理生成，利用高分辨率多视角法线观测与显式可微优化替代耗时的 SDS 隐式蒸馏，实现高效、高质量、多视角一致且支持宽松服装的文生 3D 人体生成。

## 研究问题与动机
- 现有文生 3D 人体方法难以同时兼顾几何/纹理质量、多视角一致性、推理效率以及对宽松服装的支持。
- 基于 NeRF/DMTet 的两阶段方法依赖 2D 扩散模型的 SDS 损失进行隐式优化，单实例耗时超过 2 小时，且因缺乏 3D 结构感知易产生多面伪影与过平滑。
- 纯 3D 原生生成方法受限于高维 3D 表征与预训练 2D 扩散模型的鸿沟，通常需从头训练且真实 3D 人体数据集稀缺，泛化受限。
- SMPL 位移场方法受限于固定拓扑，无法生成宽松衣物；多视角扩散方法视角覆盖有限且分辨率不足，难以合成细节丰富的完整人体。

## 核心贡献（创新点）
- **几何-纹理解耦的显式优化范式**：放弃慢速隐式 SDS，转为显式生成 2D 多视角观测并结合维度提升进行快速 3D 合成，在保持生成多样性的同时实现数量级加速。
- **高分辨率多视角法线生成与几何雕刻策略**：设计 1024 分辨率 4 视角法线生成模块，引入交叉视图注意力保障一致性；提出可微光栅化几何雕刻，动态调整拓扑，天然支持宽松服装无需后期细化。
- **基于 SMPL UV 的纹理先验与扩散渲染器**：提出形状对齐扩散模型+UV 修复构建全局纹理先验；设计含 RenderNet 与 ReferenceNet 的双模块扩散渲染器，实现 360° 密集视角高分辨率一致纹理渲染。

## 方法详解
方法分为几何生成与纹理生成两阶段，核心设计如下：
- **多视角人体法线生成 (Sec 3.1)**：以 SMPL 模板 `M(θ, β)` 的四视角渲染图经 VAE 编码为隐向量，结合 CLIP 文本嵌入与 MLP 相机嵌入，输入预训练 LDM 生成 1024 分辨率的前/后/左/右法线图。在 UNet 自注意力层引入 cross-view interaction，将其他视角中间特征作为 query/value，实现视图间信息融合。训练采用 v-prediction 目标（公式1），推理时开启 10% 概率空白文本实现 Classifier-Free Guidance。
- **法线驱动的人体几何雕刻 (Sec 3.2)**：将世界坐标系四视角法线贴图解码为梯度信号，通过可微光栅化器与初始 SMPL 网格逐像素对齐，最小化法线 L1 损失、轮廓掩码损失及邻面法线余弦正则（公式2，λ=1）。每步优化后进行动态 remeshing 合并/分裂三角面，使拓扑随宽松服装自适应变化，最终输出显式网格 M_h。
- **基于 SMPL 的纹理先验获取 (Sec 3.3)**：针对 4 视角 RGB 遮挡严重的问题，先用形状引导扩散模型（Pix2Pix 形式）以法线图为条件生成与几何对齐的正面初始观测 I_0^init（公式3）。再将其投影至 SMPL UV 空间，通过光线投射计算可见性掩码，利用微调的 Stable Diffusion 修复模型补全不可见区域（公式4），得到完整 SMPL UV 纹理图。最后通过顶点着色映射到 M_h，得到粗粒度纹理网格 M_h^vc。
- **扩散渲染器纹理绘制 (Sec 3.4)**：渲染器由主 RenderNet 与参考 ReferenceNet 组成。RenderNet 接收相机参数、粗 RGB 先验 I^vc 与法线图 N，生成 k=32 个环绕视角的高清观测；ReferenceNet 提取 I_0^init 与 N_0^init 的特征，通过特征求和注入 RenderNet 的自注意力层，强制维持多视角身份一致性（公式5、6）。训练分两阶段：先训 RenderNet，再冻结 RenderNet 仅优化 ReferenceNet。最终将 32 个渲染观测经 XAtlas UV 展开后，联合
