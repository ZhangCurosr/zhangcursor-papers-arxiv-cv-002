# 论文速读：PolarSym: Polar Geometry-aware Attention for CAD Floorplan Parsing

## 一句话总结
本文提出了一种基于极坐标几何感知注意力的CAD平面图解析框架PolarSym，通过将建筑几何关系显式解耦为方向与距离两个互补因子并独立建模，有效增强了Transformer对建筑平面图中长程对称结构的建模能力，在公开基准上相比SymPoint V2基线实现了PQ +1.73%、mIoU +4.31%的性能提升。

## 研究问题与动机
1. **现有Transformer方法几何建模不足**：当前基于Transformer的CAD平面图解析方法主要依赖语义相似性构建注意力，空间几何关系仅通过位置编码隐式表示，缺乏对建筑结构几何对称性的显式建模。
2. **长程对称结构难以建立稳定对应**：面对重复布局、镜像结构或长程对称目标时，仅依赖语义相似性的注意力机制倾向于退化为局部关联，无法建立可靠的远端结构对应关系。
3. **笛卡尔坐标系的几何表达局限**：现有位置编码或距离偏置通常采用统一的笛卡尔坐标，将方向和距离信息混合编码或假设距离与相关性呈单调关系，无法准确描述建筑平面图中广泛存在的长程对称结构。
4. **建筑图纸的几何特殊性**：建筑组件沿建筑主轴线呈规则轴对称或重复分布，其结构关系需同时满足方向一致性（Direction Consistency）和径向对应（Radial Correspondence），现有方法未能充分利用这一先验。

## 核心贡献（创新点）
1. **提出极坐标几何感知注意力框架PolarSym**：与传统位置编码不同，PolarSym在注意力层显式解耦建筑组件间的几何关系为方向与距离两个独立因子，提供了CAD平面图解析的统一几何建模框架，区别于现有方法将空间信息统一编码为位置嵌入的做法。
2. **设计方向-距离协同建模机制**：提出了基于SF-RoPE（分裂特征旋转位置编码）的方向建模方法和基于RDB（共振距离偏置）的径向建模方法，并通过动态门控策略实现两种几何模态的自适应融合，本质区别在于将方向与距离独立建模而非联合编码。
3. **轻量级动态门控融合策略**：引入可学习的门控系数α、β控制两个几何分支的贡献，采用tanh参数化约束系数范围，并通过非对称初始化策略（方向门初始值较大、径向门初始值为0）实现训练过程的协同优化，避免修改原始Transformer架构。
4. **系统的实验验证与收敛分析**：在公开CAD平面图解析数据集上验证了方法有效性，不仅提升了最终性能（PQ +1.73%、mIoU +4.31%），还显著加快了收敛速度（20 epoch时PQ达74.6%，基线仅58.1%），证明了几何建模优化效率的提升而非单纯容量增加。

## 方法详解
**整体框架**：给定Point Transformer骨干网络提取的N个点特征F ∈ R^(N×D)，通过线性投影生成查询Q、键K、值V，层ID特征经LFEM模块增强后输入PolarSym解码器模块，通过两个并行几何分支增强注意力分数。

**几何注意力公式**：
$$S = S^{sem} + \alpha \Delta^{dir} + \beta B^{rad}$$
其中S^sem为原始语义注意力，Δ^dir为SF-RoPE产生的方向增强项，B^rad为RDB学习的径向距离偏置，α、β为可学习门控系数。

**方向建模（SF-RoPE）**：
- 不同于传统RoPE对相邻特征对进行旋转，SF-RoPE将特征维度分为两部分x^(1)和x^(2)，执行跨半特征旋转：
$$\left[x'_{k+D/2}\right] = \left[\begin{array}{cc}\cos\theta_k & -\sin\theta_k\end{array}\right]\left[\begin{array}{c}x_k\\x_{k+D/2}\end{array}\right]$$
- 旋转角度由物理坐标决定：θ_k = λφ(p_i)，其中φ(p)为角度映射函数，λ为可学习频率缩放因子
- 不同注意力头交替采用水平/垂直坐标编码两个主轴的方向信息
- 方向增强项：Δ^dir = S^dir - S^sem，不替代语义注意力而是估计几何诱导的注意力增量

**径向建模（RDB）**：
- 计算两点欧氏距离d_ij = ||p_i - p_j||_2
- 将距离转换为Fourier特征表示：
$$\gamma(d_{ij}) = [d_{ij}, \sin(2^0\pi d_{ij}), \cos(2^0\pi d_{ij}), ..., \sin(2^{L-1}\pi d_{ij}), \cos(2^{L-1}\pi d_{ij})]$$
- 通过轻量MLP预测径向注意力偏置：B^rad = MLP(γ(d_ij))
- Fourier编码使网络能学习多峰周期性距离响应，对远距离但具有结构对应性的点对赋予更高注意力

**动态门控策略**：
- 门控系数参数化：α = tanh(g_α), β = tanh(g_β)
- 非对称初始化：g_α = 2.0 (α_init ≈ 0.96)确保方向几何从初始参与注意力；g_β = 0 (β_init = 0)初期抑制径向分支
- 训练过程中网络逐步增加β，在建立可靠的语义和方向表示后才引入径向几何

## 实验与结果
**数据集与评估指标**：在公开CAD平面图解析基准上评估，使用全景分割指标PQ、RQ、SQ和语义分割指标mIoU。

**对比实验**：
- 与现有SOTA方法对比：PolarSym以50个epoch的训练成本，达到87.15% PQ，优于PanCADNet (59.5%)、GAT-CADNet (73.7%)、SymPoint V1 (83.3%)，与官方报告的SymPoint V2 (90.1%, 250 epoch, 8 GPU, batch 16)相比更具效率优势。
- **公平对比（相同训练配置）**：重新实现的SymPoint V2基线 vs PolarSym：

| Method | PQ (%) | RQ (%) | SQ (%) | mIoU |
|--------|--------|--------|--------|------|
| SymPoint V2 (Reproduction) | 85.42 | 89.92 | 94.98 | 66.56 |
| PolarSym (Ours) | 87.15 | 91.46 | 95.28 | 70.87 |
| **相对提升** | **+1.73** | **+1.54** | **+0.30** | **+4.31** |

**消融实验**：
- Baseline → +SF-RoPE：PQ从85.42%提升至86.83%，mIoU提升2.60%
- +RDB：PQ进一步提升至87.15%，mIoU达70.87%，证明方向与径向建模的互补性
- 与标准轴向RoPE+线性距离偏置对比：在弱基线设置下PolarSym仍保持显著优势（Final PQ: 87.15% vs 83.57%）

**收敛分析**：20 epoch时PolarSym PQ达74.6%，而基线仅58.1%，显式几何建模使网络在早期即建立全局结构对应关系。

## 相关工作脉络
1. **SymPoint系列**：将Point Transformer引入CAD平面图解析的代表性工作，通过逐点特征交互实现竞争性的实例级解析性能，但忽略了几何层信息且收敛缓慢；SymPoint V2通过LFE模块和PGT方法改进，本文在相同配置下进一步超越。
2. **CADTransformer**：首次证明Transformer可有效学习CAD图元间的长程上下文关系，但token特征仍依赖HRNet提取的栅格图像特征，位置编码主要使用绝对坐标编码，无法表达方向与距离关系。
3. **PanCADNet / GAT-CADNet**：基于GCN的方法，通过图卷积学习图元间的拓扑关系，但图构建和消息传递过程计算开销大，尤其在实体数量多的复杂建筑中训练和推理效率下降。
4. **VectorFloorSeg**：双流GNN注意力网络，分别学习线边界和区域信息，但存在最小区域误分类、形态相似类别区分困难等问题，且仅支持直线段。
5. **CADSpotting**：通过密集采样点表示基本几何形状实现全实例分割，但缺乏全局拓扑特征，稳定性较差。
6. **DeepSVG**：利用Transformer层次结构学习矢量图形表示，但全局注意力计算时间复杂度随元素数量急剧增长，空间表示主要依赖形状位置，缺乏显式方向、距离和拓扑约束建模。

## 局限性与未来方向
**局限性**：
1. 几何建模目前主要局限于2D平面结构，尚未扩展到3D建筑模型。
2. 未涉及跨模态建筑数据（如结合3D点云与2D图纸）的几何注意力建模。
3. 对复杂空间拓扑关系（如非轴对称、非线性布局）的建模能力有待验证。
4. Fourier特征频带数量L等超参数可能需要针对不同数据集调优。

**未来方向**：
1. 探索更通用的几何注意力机制，包括统一建模3D建筑模型。
2. 研究跨模态建筑数据的几何感知注意力。
3. 处理更复杂的空间拓扑关系，扩展至非规则布局场景。
4. 结合建筑领域知识设计更精细的几何先验。

## 研究启发与可借鉴点
1. **几何信息解耦建模的范式**：将空间几何关系解耦为独立因子（如方向、距离）分别建模，而非统一编码为位置嵌入，这一思路可迁移至其他需要显式几何建模的任务（如点云理解、3D场景解析）。
2. **SF-RoPE的跨半特征旋转设计**：通过跨特征维度 halves 的旋转实现全局通道交互，这一设计可推广至其他需要长程依赖建模的序列任务。
3. **Fourier特征建模非单调距离响应**：使用Fourier编码学习周期性/多峰距离响应函数，突破了传统距离偏置的单调衰减假设，适用于存在对称结构的场景。
4. **动态门控的非对称初始化策略**：方向门初始值大、径向门初始值为0的策略，可借鉴用于多分支模型训练中不同分支的协同优化。
5. **与现有架构的无缝集成**：通过加性注意力调制而非特征变换注入几何信息，使得方法可无缝集成到现有Transformer架构中，为后续工作提供了低成本的改进路径。

## 关键术语表
**CAD Floorplan Parsing**：从2D工程图纸中自动识别并重建墙体、门窗、家具等建筑组件的结构化语义表示任务。
**Panoptic Quality (PQ)**：全景分割综合评估指标，融合像素级分割质量(SQ)和实例级识别质量(RQ)，定义为PQ = SQ × RQ。
**SF-RoPE (Split-Feature Rotary Position Embedding)**：分裂特征旋转位置编码，将特征维度分为两半并执行跨半旋转，实现长程方向一致性建模。
**RDB (Resonant Distance Bias)**：共振距离偏置，通过Fourier特征编码学习非单调距离响应函数，对远距离但结构对应的点对赋予高注意力。
**Direction Consistency**：方向一致性，描述两个建筑组件是否满足相同的对称变换关系。
**Radial Correspondence**：径向对应，量化两个组件在建筑对称性下是否具有兼容的几何距离。
**Point Transformer**：基于点集表示的点云Transformer架构，通过点级特征交互捕捉不同建筑组件间的语义关系。
**Dynamic Gating Mechanism**：动态门控机制，通过可学习系数α、β自适应控制方向与径向两个几何分支对注意力的贡献。
