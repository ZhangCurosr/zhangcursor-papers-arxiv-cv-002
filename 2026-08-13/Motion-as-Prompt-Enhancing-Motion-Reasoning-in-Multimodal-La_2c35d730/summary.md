# 论文速读：Motion-as-Prompt: Enhancing Motion Reasoning in Multimodal Large Language Models via Motion-Guided Cross-Frame Visual Prompting

## 一句话总结
本文提出 **Motion-as-Prompt (MaP)**，一种无需训练、可插拔的跨帧视觉提示框架，通过从全帧率视频中恢复密集点轨迹并在稀疏采样帧上显式标记帧间运动，使冻结 MLLM 能直接感知对象位移、方向变化和动态交互；在 CLEVRER 和 SSv2 两个运动推理基准上，分别对 GPT-5.5 实现 +4.2% 和 +8.9% 的平均准确率提升，且不损害非运动任务的泛化能力。

## 研究问题与动机
- **稀疏均匀采样的帧间运动损失（inter-frame motion loss）**：MLLMs 为控制视觉 token 与注意力开销，通常仅处理少量均匀采样帧（如 1 FPS），导致碰撞、加速、方向转折等关键过渡事件在采样帧之间完全不可见。
- **现有运动感知方法依赖训练/架构修改**：专门引入运动表征、时空建模或任务特定微调的工作需访问模型权重或重新训练，不适用于闭源/冻结 MLLM。
- **现有视觉提示多为单帧局部**：SoM、GoM 等方法在单帧内标注对象区域、身份或空间关系，能回答"是什么/在哪"，却无法揭示"如何在未采样区间运动"，与跨帧证据存在本质错位。
- **运动引导的关键帧选择比语义引导更适合运动推理**：CLEVRER 等基准的关键证据是连续过渡而非显著语义变化，基于语义相关性的选择（AKS、FOCUS）在运动任务上显著退化。

## 核心贡献（创新点）
- **识别并形式化"帧间运动损失"这一输入端瓶颈**：与以往从模型侧补救不同，本文指出问题根源在于稀疏采样丢弃了连续运动证据，需在输入侧恢复。
- **提出跨帧运动恢复提示（cross-frame motion-recovery prompting）**：与 SoM/GoM 的单帧标注本质不同，MaP 将两帧之间的累积轨迹直接渲染为可视化折线，使隐藏运动变为可见提示。
- **构建端到端无训练框架 MaP（运动引导采样 + 帧间轨迹标记）**：无需修改 MLLM 架构或微调，仅通过预处理改变视觉输入分布即可生效。
- **设计三维度运动能量分数（速度 spd、加速度 acc、曲率 cur）**：显式捕捉快速移动、加速/减速与方向改变三类运动线索，并做 95 分位数归一化与中值平滑。
- **证明轨迹标记的收益随帧预算增大而增大**：反直觉发现——更密采样使轨迹表示更保真，标记价值更高，提示应兼顾"缺失多少运动"与"能否高保真表达运动"。

## 方法详解
**整体流程（Figure 2）**：给定全帧率视频 V 与文本提示 T，MaP 作用于视觉输入，产出增广帧序列 MaP(V)，送入冻结 MLLM 进行推理。

1. **密集点轨迹恢复**：使用冻结点跟踪器（CoT-rack3）在整段视频中跟踪 G×G（默认 10×10）查询点网格，每隔固定间隔（如 1 s）重新 seeding 以捕捉新进入的对象，得到点迹 p_ℓ^i 与可见性标志 o_ℓ^i。

2. **相机运动补偿查询点速度**：原始相邻帧位移同时包含对象运动与相机自运动。用全局相似变换 S_θ(p)=sp+tb 拟合所有可见点的共同运动分量 θ=(a,b,t_x,t_y)（含平移、旋转、尺度），以最小二乘求解；对象速度为残差 v_ℓ^i = (p_{ℓ+1}^i - p_ℓ^i) - (S_{θ*}(p_ℓ^i) - p_ℓ^i)。静态相机下补偿近似恒等变换。

3. **运动能量分数 M(ℓ)**：沿速度、加速度、曲率三个互补维度聚合：
   - spd_ℓ = 平均归一化速度
   - acc_ℓ = 平均归一化速度变化
   - cur_ℓ = 平均归一化转向角（按较小相邻速度加权，避免近静态点产生虚假曲率）
   各维度经 95 分位数 clip 归一化后等权相加，再用长度 w=3 的移动平均平滑，最终 M(ℓ)∈[0,1]。

4. **运动引导采样（Algorithm 1）**：在固定帧预算 B 下选择 S'（|S'|=B）：
   - **覆盖锚点**：均匀抽取 n_a=⌈αB⌉（α=1/4 默认）个全局锚点，防止运动峰值过度聚类。
   - **峰值选择 + 时间 NMS**：按 M(ℓ) 降序贪婪选取，相邻已选帧间隔至少 r=⌊N/(2B)⌋ 帧（约均匀采样间隔的一半），允许峰值区密度达到均匀采样的两倍但不集中于单点。
   - **重要性采样兜底**：若 NMS 不足 B 帧，按运动能量剩余填充。

5. **帧间轨迹标记（Inter-frame trajectory marking）**：对每对相邻采样帧 (s_{k-1}, s_k)：
   - **运动点筛选**：仅保留在后续 Δ 帧内最大位移 > τW（τ=0.03）的点，并按总运动排序至多保留 K 个点，避免视觉杂乱。
   - **轨迹渲染**：将累积轨迹段 γ_k^i = (p_ℓ^i)_{ℓ=s_{k-1}}^{s_k} 以单色折线画在第 s_k 帧上，终点用圆形标记；所有轨迹叠加于视觉输入，形成 Set-of-Marks 风格的跨帧提示。

## 实验与结果
**基准与模型**：
- **CLEVRER**（合成运动密集型推理，5 个子任务：OE/MD/MC/MA/CI）与 **SSv2-v2**（真实世界细粒度人-物交互，抽象为"something"选项消除对象识别捷径）；另加 **TempCompass**（非运动视频推理，检验泛化）
- 模型：**Qwen3-VL-2B-Instruct**（本地权重，冻结）与 **GPT-5.5**（远程 API，冻结）；点跟踪器 CoT-rack3，1 FPS 采样

**主要结果（Table 1）**：
- **CLEVRER 平均**：GPT-5.5 从 uniform 的 74.9% 提升至 MaP 的 79.1%（+4.2%）；Qwen3-VL-2B 从 57.6% 提升至 60.4%（+2.8%）。MaP 在 5 个子任务中占优或持平，显著优于 AKS/FOCUS/SoM/GoM 等基线。
- **SSv2**：GPT-5.5 从 71.1% 提升至 80.0%（+8.9%，最强提升）；Qwen3-VL-2B 从 51.8% 提升至 53.2%（+1.4%），低于 FOCUS（57.2%），作者归因 SSv2 选项与对象语义识别强相关，有利于语义关键帧选择。
- **TempCompass（Table 2，非运动泛化）**：MaP 在 Qwen3-VL-2B（67.6% vs 67.3%）与 GPT-5.5（88.6% vs 88.3%）上均持平或微升，说明运动引导采样不因聚焦运动而损害通用视频理解。
- **逐子任务亮点**：CLEVRER 的 CI（counterfactual inference）GPT-5.5 达 75.5%，较 uniform 的 63.0% 提升 12.5 个百分点，显示因果/反事实运动推理收益最大。

**超参数与效率（Table 3）**：
- 单视频预处理时间：CLEVRER 约 5.12 s 视频 783 ms、SSv2 约 4.21 s 视频 609 ms、TempCompass 约 10.88 s 视频 1920 ms；远低于 SoM（43 s）、GoM（23 s）。
- GPU 内存平均开销 0.35 GB，峰值 3.41 GB，显著低于 SoM/GoM。

**消融（Figure 4–5）**：
- 轨迹标记对 GPT-5.5/Qwen3-VL-2B 分别贡献 +1.3%/+1.8%，运动引导采样再各贡献 +1.0%；标记是主要增益来源。
- 帧预算敏感性：轨迹标记增益随采样率从 0.5→2 FPS 单调增大，反直觉地说明"标记价值取决于轨迹保真度而非仅缺失量"。

## 相关工作脉络
- **Adaptive Keyframe Sampling (AKS)**：基于语义相关性与时间覆盖度的关键帧选择；与 MaP 差异在于 AKS 关注"帧内什么显著"而忽略"帧间如何变化"。
- **FOCUS**：从语义线索估计帧重要性；在 SSv2 上优于 MaP，但在 CLEVRER 上显著退步，体现任务依赖。
- **Set-of-Mark (SoM)**：在像素级叠加分割掩码与编号；擅长对象定位类任务（如 MD 子任务），但对复杂跨帧因果推理干扰较大。
- **Graph-of-Mark (GoM)**：将对象与空间关系编码为场景图提示；开销大（峰值内存 9.55 GB），且静态图无法表达动态演化。
- **Flow4Agent / DynImg / MotionSight**：引入光流先验或非关键帧作为提示；均需特定表示或后训练，MaP 则保持零训练与模型无关。
- **VideoExp、TimeChat、VTimeLLM、Seq2Time、SlowFocus、Time-R1**：从模型侧增强时空建模或微调；MaP 的对比定位是"只做输入侧变换，完全不碰模型"。

## 局限性与未来方向
- **点跟踪器在快速运动、严重遮挡、重复纹理下的失效**会直接削弱轨迹质量与标记可用性；文中未系统评估此类失败模式。
- **运动能量设计依赖速度/加速度/曲率的加权组合**，权重与窗口 w 均为手工设定，未做自适应学习；对低频但有语义意义的缓慢位移可能敏感度不足。
- **SSv2 上 Qwen3-VL-2B 增益有限**，暴露小模型在视觉密集场景中解读轨迹叠加的能力上限，也提示标记密度（K、τ）需随模型规模调整。
- **0.5 FPS 下轨迹退化为粗线段**，低帧预算时标记甚至可能遮蔽原始视觉证据；未来需研究极稀疏条件下的替代编码（如摘要式矢量而非像素折线）。
- **未探讨音频/深度等多模态线索的融合**；若视频含声效或深度信息，运动恢复可从多模态三角测量进一步提纯。
- **长期视频（>10 min）的时间窗口扩展**：当前窗口化重 seeding 策略在超长视频下的计算与内存可扩展性未验证。

## 研究启发与可借鉴点
- **输入侧"证据恢复"优于输出侧"模型增强"**：在不改动 MLLM 的前提下，通过提示将缺失的运动证据显式化，是一条低成本、高迁移性的优化路径，可推广至其他"采样丢失证据"场景（如异常检测中的瞬态事件）。
- **三维度运动能量设计（spd/acc/cur）可作为通用运动显著性度量**：其曲率加权策略（避免静态点虚假响应）值得借鉴到关键帧选择、动作定位、视频摘要等任务。
- **轨迹标记密度控制（τ、K）与帧预算的联合调参经验**：实验揭示"更密采样 + 标记"组合优于"极稀疏 + 标记"，提示在资源规划时应优先保证帧预算而非激进出力压缩。
- **小模型与大模型对同一提示的吸收能力差异显著**：SSv2 上 Qwen3-VL-2B 的有限收益提醒我们，视觉提示的有效性高度依赖下游模型的感知与推理带宽，需建立"提示-模型规模"匹配策略。
- **可复现的流水线范式**：冻结跟踪器 → 相机补偿 → 运动能量 → 峰值采样 → 轨迹叠加，五个模块均可独立替换（如换成 DINO 特征或光流），为后续工作提供模块化扩展基座。

## 关键术语表
- **Inter-frame motion loss（帧间运动损失）**：稀疏均匀采样导致相邻采样帧之间连续运动证据（加速、碰撞、转向）完全不可见的输入端瓶颈。
- **Motion-guided sampling（运动引导采样）**：基于运动能量分数而非语义显著性，在固定帧预算下选择最能表征动态过程的帧的子集。
- **Trajectory marking（轨迹标记）**：将相邻采样帧之间的点迹累积段渲染为单色折线与终点标记，叠加在后续帧上形成可见的跨帧运动提示。
- **Camera-compensated velocity（相机补偿速度）**：从原始点位移中减去全局相似变换（平移+旋转+尺度）拟合出的相机自运动分量，得到的相对对象速度残差。
- **Motion energy score M(ℓ)**：综合速度 spd、加速度 acc、曲率 cur 三维度并做 95 分位数归一化与平滑后的单帧运动显著性标量。
- **Non-maximum suppression (NMS) for temporal sampling（时间非极大值抑制）**：在运动能量降序贪婪选帧时，强制任意两帧之间至少间隔 r 帧，防止峰值过度聚类。
- **Set-of-Marks style prompt（Set-of-Marks 风格提示）**：在像素空间以可见线条、掩码、编号等方式叠加的视觉提示，区别于嵌入空间的 learnable prompt tokens。
- **Counterfactual inference (CI)**：CLEVRER 中"若移除某对象会发生何事"的因果/反事实推理子任务，对连续运动证据最为敏感。
