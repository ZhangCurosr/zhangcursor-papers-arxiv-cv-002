# 论文速读：Repurposing-RGB-based-Foundation-Model-for-Depth-Estimation

## 一句话总结
提出 RGB-HS 框架，通过分层监督（对齐 + 验证）将 RGB 基础模型（DINOv3）的丰富表征迁移到热成像深度估计，实现仅用热图输入即达到超越现有 Stereo 方法的精度，且推理时不依赖 RGB 图像。

## 研究问题与动机
- **热图深度估计的文本缺失问题**：热成像仅捕捉温度对比，缺乏纹理和颜色信息，导致物体边界模糊、空间梯度弱，直接估计深度困难。
- **现有方法未充分利用 RGB 基础模型的多层表征**：GTDE [15] 利用 DINOv2 特征但忽略了 RGB 模态本身；RGB-MDE [16] 从 RGB 图像蒸馏知识但忽视了基础模型中间 token 的结构/语义信息。
- **不同环境下 RGB 监督信号质量不均**：低光照或恶劣天气下 RGB 特征可靠性下降，现有方法将所有 RGB 监督一视同仁，未识别并过滤低质量样本。
- **热图数据稀缺**：相比 RGB，热图标注数据量少，需要借助 RGB 基础模型的大规模预训练先验来弥补。

## 核心贡献（创新点）
1. **提出 RGB-HS 框架，利用分层监督从 RGB 基础模型迁移知识到热图深度估计**——与 GTDE/RGB-MDE 的本质区别在于同时利用 RGB 模态本身和基础模型多层 token 表征。
2. **设计两水平对齐机制（Map-level + Latent-level）**——Map-level 通过相关性损失保证局部结构一致性，Latent-level 通过余弦相似度 + KL 散度保证全局语义分布一致性，两者互补。
3. **引入基于亮度-对比度的验证模块自适应过滤低质量 RGB 监督**——通过评估 RGB 图像质量动态调整对齐权重，避免不可靠 RGB 信号压制热图模态的独特能力。
4. **在 MS² 数据集上实现 SOTA 性能，且推理时不依赖 RGB 输入**——RGB-HS (Stereo) 平均 AbsRel=0.105、RMSE=3.548，超越所有基线，包括之前最佳的 Stereo 方法。

## 方法详解

### 整体架构
采用教师-学生范式：冻结的 RGB 教师分支（DINOv3 ViT-B/16）提供丰富的监督信号，热图学生分支（同样架构）从教师学习表征以预测深度。编码器提取多层特征 {F_l}_{l=1}^L，解码器 g_φ 处理热图特征估计密集深度图。

### 分层对齐机制

**Map-level 对齐（局部结构）**：
- 将 transformer 的空间 patch tokens 重塑为 2D 特征图 F_l ∈ R^{C_l × H_l × W_l}
- 计算通道级相关性对齐损失：L_corr = (1/C) Σ_c ||f_THR,c^T f_THR,c - f_RGB,c^T f_RGB,c||₂²
- 该损失迫使热图特征与 RGB 特征在空间依赖关系上保持一致，强化边缘和深度不连续处的结构

**Latent-level 对齐（全局语义）**：
- 对每个特征图做空间最大池化得到全局隐表征 f̄ ∈ R^C
- 余弦相似度损失：L_cos^g = 1 - <f̄_THR, f̄_RGB> / (||f̄_THR||₂ ||f̄_RGB||₂)
- KL 散度损失（温度参数 T）：L_KL^g = KL(Softmax(f̄_RGB/T) || Softmax(f̄_THR/T))
- 联合损失：L_latent = λ₁ᵍ L_cos^g + λ₂ᵍ L_KL^g

### 验证模块
- 计算 RGB 图像的亮度置信度 C_BT = 平均亮度，对比度置信度 C_CT = 亮度标准差（归一化到 [0,1]）
- 综合置信度 C_RGB = (C_BT + C_CT) / 2
- 用 C_RGB 加权验证后的热图特征参与对齐损失计算，低质量 RGB 样本的对齐权重自动降低

### 总损失函数
L_total = L_baseline + (1/NL)(ΣΣ L_map^(n,l) + ΣΣ L_latent^(n,l))
其中 L_baseline 为基线 MSCRF 的监督回归损失，N 为 batch size，L 为编码器层数。

**推理时仅保留热图编码器-解码器，不依赖 RGB 输入。**

## 实验与结果

### 数据集
MS² (Multi-Spectral Stereo) 数据集：包含同步的立体 RGB、NIR 和热成像数据及立体 LiDAR 真值，涵盖白天/夜晚/雨天等多种光照和天气条件。训练 26K、验证 4K、测试 17.8K 配对样本。

### 主要结果（MS² 数据集，立体深度估计）
| 方法 | Avg AbsRel | Avg SqRel | Avg RMSE | δ<1.25 |
|------|-----------|-----------|----------|--------|
| MSCRF (Stereo) | 0.120 | 1.057 | 5.068 | 0.872 |
| **RGB-HS (Stereo)** | **0.105** | **0.572** | **3.548** | **0.887** |
| RGB-HS (Mono) | 0.117 | 0.650 | 3.806 | 0.862 |

- **RGB-HS (Stereo) 在多数指标上取得最佳性能**，AbsRel 相对 MSCRF (Stereo) 提升 12.5%，SqRel 提升 45.9%，RMSE 提升 30.0%
- **RGB-HS (Mono) 超越所有之前的 Stereo 方法**，如 AbsRel 优于 MSCRF (Stereo) 的 0.015
- 夜晚场景 RMSE=3.038、雨天 RMSE=4.172，显著优于 MSCRF 的 4.584 和 5.940
- 在清洗版 MS² 数据集上，RGB-HS 的 RMSE=2.595 优于 RGB-MDE 的 2.677

### 消融实验关键结论
- **编码器选择**：ViT-B/16 (86M params) 超越 Swin-L (197M params)，证明基础模型表征有效性
- **对齐模块**：Map + Latent 联合使用效果最佳（SqRel 0.607 vs 单独使用的 0.629/0.631）
- **验证模块**：加入验证后 SqRel 从 0.607 降至 0.572，RMSE 从 3.646 降至 3.548
- **模型复杂度**：RGB-HS (249M, 0.23T FLOPs) 远轻于 RGB-MDE (666M, 0.72T FLOPs)

## 相关工作脉络

1. **GTDE [15]**：利用 DINOv2 中间 token 实现零样本热图深度估计——本文认为其忽视了 RGB 模态本身的信息，且未充分利用多层表征
2. **RGB-MDE [16]**：从 RGB 图像蒸馏知识到热图——本文认为其忽视了基础模型中间 token 的结构/语义信息，且未过滤低质量 RGB 样本
3. **MSCRF [9]**：本文采用的基线方法，首个热图深度估计深度框架——本文在其基础上替换为 DINOv3 并引入分层监督
4. **DepthAnything [8] / DepthAnythingV2 [25]**：RGB 深度估计基础模型，均使用 DINOv2 作为 backbone——本文使用更新的 DINOv3 并聚焦热图模态
5. **ThermoStereoRT [30]**：基于知识蒸馏的热图立体匹配——本文与其定位不同，RGB-HS 强调分层对齐而非直接蒸馏
6. **GTDE vs RGB-MDE vs RGB-HS**：三者均尝试跨模态迁移，但本文是首个同时利用 RGB 模态 + 多层 token 表征 + 质量验证的工作

## 局限性与未来方向

- **验证模块较简单**：仅基于亮度-对比度，未考虑语义层面的特征质量评估，可能在极端情况下不够鲁棒
- **仅在 MS² 数据集上验证**：未在其他热图深度数据集（如 ThermalDepth）上测试泛化能力
- **未探索其他基础模型架构**：仅使用 DINOv3 ViT-B/16，其他架构（如 Segment Anything Model）的效果未知
- **仅聚焦深度估计任务**：分层监督方法在其他热图任务（分割、检测、跟踪）上的有效性待验证
- **RGB 教师分支完全冻结**：未探索联合微调的可能性，可能不是最优策略

未来方向：将分层监督扩展到热图语义分割、检测和跟踪等其他视觉任务。

## 研究启发与可借鉴点

1. **"冻结教师 + 分层对齐"的范式可迁移**：本文的教师-学生+多层对齐设计可应用于其他跨模态迁移任务（如 NIR→RGB、SAR→光学），特别是当目标模态数据稀缺时
2. **验证模块的设计思路值得借鉴**：基于图像质量的自适应权重机制可用于任何跨模态蒸馏/对齐场景，防止低质量源模态干扰目标模态学习
3. **Map-level + Latent-level 互补对齐是通用策略**：局部结构对齐（相关性损失）与全局语义对齐（余弦+KL）的组合可推广到其他细粒度视觉任务
4. **推理时不依赖辅助模态**：训练时用多模态监督、推理时只用单模态的策略，在保证性能的同时降低部署成本，值得在其他跨模态学习中采用
5. **小参数替代大参数的可行性**：ViT-B/16 (86M) 超越 Swin-L (197M)，说明预训练基础模型的表征质量比参数量更重要，为轻量化部署提供思路

## 关键术语表

**Hierarchical Supervision（分层监督）**：通过多个层次（图级别和隐级别）将教师模态的知识迁移到学生模态的监督策略。

**Map-level Alignment（图级别对齐）**：在特征图空间通过相关性损失强制热图和 RGB 特征的局部结构一致性，关注边缘和深度不连续。

**Latent-level Alignment（隐级别对齐）**：通过空间最大池化聚合全局表征，利用余弦相似度和 KL 散度损失对齐全局语义分布。

**DINOv3**：最新一代自监督视觉基础模型，本文采用其 ViT-B/16 预训练版本作为 RGB 教师编码器。

**MS² Dataset（Multi-Spectral Stereo）**：大规模多光谱户外自动驾驶基准数据集，提供同步的立体 RGB、NIR 和热成像数据及 LiDAR 真值。

**Brightness-contrast Confidence（亮度-对比度置信度）**：基于 RGB 图像平均亮度和亮度标准差计算的图像质量指标，用于验证模块自适应调整对齐权重。

**MSCRF**：首个基于深度学习的热图深度估计框架，本文以其作为基线方法。

**Teacher-Student Paradigm（教师-学生范式）**：冻结的 RGB 教师分支提供监督信号，热图学生分支学习复现教师表征以完成深度估计任务。
