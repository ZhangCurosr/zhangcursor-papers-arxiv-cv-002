# 论文速读：WeMM-Embedding-WeChat-Multi-Modal-Embedding-Technical-Report

## 一句话总结
提出 WeMM-Embedding，一个基于 Qwen3.5 骨干的 2B/4B/9B 通用多模态嵌入模型家族，支持文本、图像、视频及任意交错输入与灵活维度输出；通过“大规模多模态对齐 + 策划数据精细化微调”的两阶段训练策略，在 MMEB-v2/v3 及微信内部 26 任务中达到 SOTA，并已在推荐与搜索业务中规模化落地。

## 研究问题与动机
- 早期 CLIP 类双编码器架构模态路径隔离，无法自然支持文本-图像交错文档、组合查询或视频 transcript 等多模态混合输入的联合表示。
- 现有基于 MLLM 的嵌入方法在泛化性、细粒度相关性建模及参数效率方面仍有提升空间，缺乏统一的多任务训练框架。
- 海量多模态训练数据普遍存在语义分布倾斜、噪声/事实错误多、负样本信息量低等问题，限制嵌入模型的判别力与线上稳定性。
- 工业场景（如微信）需要兼顾高参效、多模态全覆盖、多尺度输出与生产环境持续 A/B 验证的通用嵌入基座。

## 核心贡献（创新点）
1. **两阶段渐进式训练策略**：先通过数亿对异构数据进行广覆盖对齐，再在策划数据上叠加细粒度监督；与早期一次性对比微调方法不同，递进设计在维持泛化能力的同时显著增强细粒度判别边界。
2. **统一 Pair-Based 格式与多任务混合框架**：将所有异构任务抽象为 $(I, q, c, \mathcal{N}, y)$ 统一结构，配合语义目标掩码消除重复标签导致的假负样本；与现有多模态嵌入方法针对单一任务定制架构不同，本文大幅简化多任务工程复杂度。
3. **Semantic-ID 引导重采样与双向嵌入蒸馏**：利用残差 k-means 量化器提取离散语义标识并按码本密度反比采样，结合源↔目标双边相似度分布蒸馏；与仅依赖人工筛选或硬负样本的方法不同，本文以低成本方式实现数据均衡与细粒度结构传递。
4. **原生 MRL 与交错多模态 Last-token 聚合**：在 Qwen3.5 骨干末尾追加 `<embedding>` token，单次前向经前缀截断即可输出 64~2048 维嵌套表征；与固定维度或双编码器方案不同，天然适配检索/粗排/精排等多阶段工业链路。
5. **从学术 SOTA 到工业闭环的完整验证**：在 MMEB-v2/v3、12 项跨模态基准及微信 26 任务上全面领先，并在 14 个线上 A/B 测试中持续增益；与仅关注离线评测的工作不同，本文实现了从模型设计到生产部署的端到端验证。

## 方法详解
- **架构与表征聚合**：基于 Qwen3.5 原生多模态 LLM，支持任意交错的文本、图像、视频输入。在序列末尾追加专用 `<embedding>` token，经因果注意力聚合后取最后一层隐状态 $\mathbf{h}_{\text{emb}}$ 并做 L2 归一化作为输出 $\mathbf{e}_{\mathcal{D}}$。支持在序列中途插入多个 `<embedding>` token，单次前向可同时提取视频仅表征与视频+ASR 联合表征。
- **统一数据格式**：每张训练样本表示为 $z_i = (I_i, q_i, c_i, \mathcal{N}_i, y_i)$，其中 $I_i$ 为任务指令，$q_i/c_i$ 为源/目标（可为多模态交错），$\mathcal{N}_i$ 为显式硬负样本集，$y_i$ 为分级相关性分数。同类目标空间（如分类）通过语义目标掩码排除重复碰撞。
