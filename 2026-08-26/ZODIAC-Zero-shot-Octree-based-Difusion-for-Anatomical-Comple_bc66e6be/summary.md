# 论文速读：ZODIAC-Zero-shot-Octree-based-Difusion-for-Anatomical-Comple

## 一句话总结
本文提出了 ZODIAC，一种无需配对训练数据的零样本整脊 3D 形状补全框架。该方法在自适应八叉树表示上学习全脊柱解剖扩散先验，并通过推理时的“步级重加噪混合补全（blended completion）”机制将超声部分观测与先验动态融合，在真实术中不规则遮挡下显著优于依赖合成配对数据的监督基线。

## 研究问题与动机
1. **病态逆问题与严重遮挡**：术中超声受骨骼强反射与声影影响，视野有限且伴有噪声，完整脊柱解剖必须从大面积缺失的部分观测中推断。
2. **合成配对数据的分布偏差**：现有监督方法依赖合成不完整-完整配对数据训练，预设的遮挡/分割错误分布与真实患者数据不一致，导致临床泛化受限。
3. **点云表示的效率与拓扑缺陷**：点云在提升几何精度时内存与计算开销线性增长，缺乏显式表面描述；且既往方法逐椎体独立补全，忽略了腰椎作为关节结构的全局曲率与椎间位姿耦合。
4. **临床对强先验与高效率的需求**：脊柱手术导航需要快速生成连贯、解剖合理的完整网格，现有方法难以同时满足零配对依赖、全局一致性与低资源消耗。

## 核心贡献（创新点）
1. **首个零样本整脊 3D 形状补全框架**：仅使用完整解剖形状训练扩散先验，彻底消除对部分-完整配对数据的依赖，通过推理时条件融合实现补全。
2. **步级重加噪混合补全机制**：提出在每次扩散去噪步骤中对观测区域进行重加噪并融合的策略，避免直接将干净观测硬约束所引发的噪声水平分布偏移。
3. **八叉树+两阶段 DDPM 的整脊联合生成骨干**：采用 LR 阶段生成全局椎体排列与曲率、HR 阶段细化表面细节的分级扩散架构，实现单前向高效整脊重建。
4. **VAE 隐式 SDF 解码管线**：将几何八叉树压缩至低维隐空间，通过冻结的 VAE 解码器输出连续 SDF 并直接 Marching Cubes 提取无孔网格，兼顾稀疏表示与表面质量。

## 方法详解
- **八叉树表示与生成先验学习**：将完整脊柱点云递归八叉分治构建几何八叉树，通过 VAE 压缩为隐层八叉树（每个叶节点存储 $C$ 维特征向量）。VAE 解码器同步预测二进制分裂决策并重建连续 SDF，训练完成后冻结。随后训练两阶段 Denoising Diffusion Probabilistic Model (DDPM)：LR 阶段使用低分辨率 UNet 对基础深度 $D_{\mathrm{base}}$ 的分裂信号网格 $\mathbf{G}_0 \in \{-1,1\}^{8 \times 2^{D_{\mathrm{base}}}\times 2^{D_{\mathrm{base}}}\times 2^{D_{\mathrm{base}}}}$ 去噪，捕获全局拓扑；HR 阶段使用高分辨率图 UNet 对叶节点隐特征去噪，恢复精细表面。
- **零样本补全与混合融合**：推理时，将部分超声点云 $\mathbf{P}$ 栅格化为基础深度分裂信号 $\tilde{\mathbf{G}}$，并构建单向掩码 $\mathbf{m}$（观测区域为 1，未观测为 0）。初始化反向过程：$\mathbf{G}_T = \sqrt{\bar{\alpha}_T}\tilde{\mathbf{G}} + \sqrt{1-\bar{\alpha}_T}\boldsymbol{\epsilon}$。每步先由 UNet 预测无约束估计 $\hat{\mathbf{G}}_t$，再按公式融合：$\mathbf{G}_t = \mathbf{m} \odot \tilde{\mathbf{G}}_t + (\mathbf{1}-\mathbf{m}) \odot \hat{\mathbf{G}}_t$，其中 $\tilde{\mathbf{G}}_t$ 为当前噪声水平下的重加噪观测版本。该机制仅作用于 LR 阶段，确保观测区域在统计上与训练分布一致，未观测区域由先验自由演化生成。
- **训练与推理配置**：使用 504 个完整腰椎网格（VerSe20 与 TotalSegmentator 拼接+形变增强），256³ SDF 栅格化。VAE 训练 900 epoch（AdamW, lr=1e-3），LR/HR 扩散模型分别训练 1500/300 epoch（lr=2e-4）。推理使用 200 diffusion steps，单次补全约 8 秒，运行于单卡 NVIDIA RTX 4080。

## 实验与结果
- **数据集**：训练集 VerSe20 (91) + TotalSegmentator (322)；验证集含 2 个人工体模（Phantom）与 Balgrist 志愿者数据集（6 次手持/机械臂超声扫描，配对 CT 标注）。
- **评估基线**：SITD（监督逐椎体补全 SOTA）、TP-ODIAC（带配对数据的完全监督版 ZODIAC）、ZODIAC-clean（硬约束消融）。
- **指标**：Chamfer Distance (CD)、F1-score (1% 阈值)、95% Hausdorff Distance (HD95)。
- **主要结果**：
  - **vs SITD**：在志愿者数据上，ZODIAC 椎体级 CD 提升 **70%**，HD95 提升 **47%**，扫描间标准差从 ±28.42 降至 ±3.60，显著缓解真实超声噪声与不规则遮挡带来的退化。
  - **vs TP-ODIAC**：在标准志愿者数据上，整体脊柱 CD 差距仅 3%，HD95 基本持平；在 **困难子集**（大范围/单椎体完全缺失）上，ZODIAC 整体脊柱 HD95 反超 TP-ODIAC **22%**，CD 提升 19%。
  - **消融（ZODIAC vs ZODIAC-clean）**：硬约束导致整体脊柱 CD 上升 15–26%，HD95 上升 13–16%，F1 下降 5–11%，证实步级重加噪融合的有效性与必要性。
- **结论**：零样本生成先验在真实不规则遮挡下泛化更优，无需配对数据即可达到接近甚至超越监督变体的性能，尤其在临床困难场景中优势显著。

## 相关工作脉络
1. **SITD [6]**：监督逐椎体点云补全 SOTA，依赖合成遮挡配对数据；本文定位为其零样本、整脊柱联合建模的替代方案，解决分布偏移问题。
2. **US-X Complete [5]**：多模态形状恢复方法，仍依赖配对数据；本文进一步消除不完整-完整配对依赖，转向纯先验驱动。
3. **SDFusion [4]**：基于密集体素/点云的扩散补全与生成模型；本文改用八叉树稀疏表示，显著降低内存并适配整脊全局结构。
4. **OctFusion [19]**：八叉树扩散生成骨干网络；本文在其基础上引入零样本补全机制与 VAE 隐式 SDF 解码，拓展至医学解剖逆问题。
5. **Blended Diffusion / Repaint [1,11]**：图像修复/编辑中的扩散融合思想；本文将其首次适配至 3D 结构化形状补全，并创新性地加入步级重加噪策略以匹配噪声调度。
6. **OctNet [12] / O-CNN [15]**：早期八叉树深度学习工作；本文继承其稀疏体素学习能力，聚焦于可微表面生成与零样本条件重建。
