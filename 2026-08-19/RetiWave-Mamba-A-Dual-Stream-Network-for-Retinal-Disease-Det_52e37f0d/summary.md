# 论文速读：RetiWave-Mamba: A Dual-Stream Network for Retinal Disease Detection based on Multi-scale Context and Frequency-Adaptive Mamba Projection

## 一句话总结
本文提出了一种名为 RetiWave-Mamba 的双流混合网络框架，通过将输入 OCT 图像经离散小波变换（DWT）分解为低/高频分支，分别利用多尺度上下文定位模块（MCLM）和基于 Mamba 的频率自适应投影器（FAMP）进行特征学习，在 OCT-C8 数据集上以 98.25% 准确率实现了当前最优性能，同时展现出优异的噪声鲁棒性与跨数据集泛化能力。

## 研究问题与动机
- **OCT 图像固有的散斑噪声**：OCT 成像过程中生物组织后向散射产生的相干散斑噪声严重干扰边缘与细节，传统 CNN 缺乏有效的频率解耦与噪声抑制机制。
- **类间形态相似性导致的误分类**：如 CNV 与 Drusen 在 RPE 层隆起形态上高度相似，模型难以通过粗粒度全局上下文区分细微纹理差异。
- **多尺度特征融合中的噪声传播**：现有 HRNet 等多尺度架构依赖简单的逐元素相加/拼接进行跨尺度融合，导致低频分支的背景噪声直接传递至高分辨率分支，污染高频特征。
- **长程依赖建模的效率瓶颈**：Transformer 类方法虽能捕获全局上下文，但二次计算复杂度难以直接应用于高分辨率医学图像；标准 Mamba 因全局平滑倾向而丢失局部精细纹理。

## 核心贡献（创新点）
1. **提出双流空间-频率混合架构 RetiWave-Mamba**：利用 DWT 将 OCT 图像解耦为低频结构流与高频细节流，分别由 MCLM 与 AG-HRNet+FAMP 处理，实现结构与纹理的并行互补学习；与以往单分支或简单频域增强方法相比，本设计通过双路径隔离了噪声传播路径。
2. **设计多尺度上下文定位模块 MCLM**：MCLM 将多尺度空洞融合（MDF）与小波空间注意力（MSW_SA）级联，在扩大感受野的同时利用小波变换在注意力生成阶段内置高频降噪能力；区别于 ASPP 需额外大参数量、SE/CBAM 无法滤除散斑噪声等问题。
3. **提出注意力引导的高分辨率网络 AG-HRNet**：用智能门控融合机制（AGF）替代 HRNet 中的简单相加，选择性放大可靠纹理并抑制背景散斑跨尺度传播；与标准 HRNet 相比，虽总体精度相近，但显著降低 CNV/Drusen 等难分类别的误判率。
4. **提出频率自适应 Mamba 投影器 FAMP**：在 Mamba 序列建模前引入 SE 式频带门控将特征分为低频/高频两条路径，并由 Mamba 输出自适应通道权重进行重加权融合；相比标准 Mamba 全局建模易平滑局部细节的问题，FAMP 保留了利于区分形态相似病变的精细纹理。
5. **在 OCT-C8 上实现 SOTA 98.25% 准确率，并在外部 OCT2017 数据集达到 99.60%，同时展示强噪声鲁棒性**：即使在 26.22 dB 极端噪声下仍保持 97.79% 准确率，超过无噪声条件下 ResNet-50 的基线水平。

## 方法详解
- **整体架构**：输入图像经 Haar DWT 分解为 1 个低频子带（LL）与 3 个高频子带（LH、HL、HH）。低频分支送入含 ResNet-50 主干（4 个 Stage）的低频流，Stage 1–3 后各插入一个 MCLM，Stage 4 输出经 GAP 得到低频嵌入；高频分支将 3 个高频子带沿通道拼接为 9 通道输入，送入 AG-HRNet（保留 4 条并行高分辨率分支），四条多尺度输出分别经独立的 FAMP 处理后拼接+GAP 得到高频嵌入，最终两嵌入拼接送入分类头。
- **DWT 分解（Sec. 3.2）**：采用 Haar 小波，沿行、列方向依次用低通 $L$ 与高通 $H$ 滤波并 2× 下采样，得到：$I_{LL}$（近似）、$I_{LH}$（水平细节）、$I_{HL}$（垂直细节）、$I_{HH}$（对角细节）；高频三路沿通道维度拼接，保留方向性信息。
- **MCLM（Sec. 3.3）**：由 MDF 与 MSW_SA 两级联构成。
  - MDF：先经 1×1 降维，再并行执行 1 条标准卷积 + 3 条空洞率 $\{6, 12, 18\}$ 的空洞卷积，逐元素相加后经 1×1 升维并残差连接回原始输入，有效扩大感受野同时避免栅格效应。
  - MSW_SA：对中间特征 $F$ 分别做 max/avg pooling 求和，送入 4 支并联 WTConv（小波卷积），经 BN 求和、1×1 卷积与 sigmoid 生成空间注意力图 $M_S$，再逐元素加权并残差连接：$y = F + (F \otimes M_S)$，利用小波分解在注意力生成阶段天然滤除高频散斑。
- **AG-HRNet（Sec. 3.4）**：在 HRNet 多尺度并行分支基础上，将所有跨分辨率特征交互（上采样/下采样方向）均替换为 Attention-Guided Fusion（AGF）门控：对源特征 $F'_l$ 经 1×1 卷积+BN+sigmoid 生成门控 $G$，再 $y_{fused} = F_h + (F'_l \otimes G)$ 残差相加，实现噪声感知的选择性特征传播。
- **FAMP（Sec. 3.5）**：输入 $X$ 经 GAP+1×1 卷积+sigmoid 得到通道掩码 $M$，将 $X$ 分割为低频分量 $X_L = X \otimes M$ 与高频分量 $X_H = X \otimes (1-M)$；两分量通道拼接后经全局池化、展平、归一化得序列 $X_{seq}$，送入 Mamba 建模长程依赖，再通过投影+sigmoid 得到通道权重 $W$，拆分得 $W_L, W_H$ 对两路分别重加权，相加后经 Fusion 块（1×1 卷积+BN+ReLU）与残差连接输出 $Y = X + F_{fusion}((X_L \otimes W_L) + (X_H \otimes W_H))$。
- **训练设置**：加权交叉熵损失、Adam（$\beta_1=0.9, \beta_2=0.999$, weight decay=1e-4）、余弦退火学习率（初值 2e-4，5 epoch warm-up）、batch size=32、60 epoch、AMP 混合精度；训练集 21,200 张（合并原 train+val），测试集 2,800 张；为增强噪声鲁棒性，训练过程采用三阶段渐进式散斑噪声注入（Phase 1 σ∈[0, 0.1] p=0.5；Phase 2 σ∈[0.05, 0.15] p=0.8；Phase 3 σ∈[0.1, 0.2] p=1.0）。

## 实验与结果
- **数据集**：OCT-C8（24,000 张，8 类各 3,000 张：AMD、CNV、CSR、DME、DR、Drusen、MH、Normal）；训练/测试划分调整为 21,200/2,800。外部验证使用 OCT2017 测试集（1,000 张，4 类各 250 张）。
- **评估指标**：Accuracy、Precision、Sensitivity、F1-score。
- **主要结果（OCT-C8）**：RetiWave-Mamba 达到 98.25% 准确率、98.27% 精确率、98.25% 召回率与 F1；相较 ResNet-50 基线提升 +0.64%；全面超越 InceptionV3（97.96%）、DenseNet121/EfficientNet-B3（97.89%）、WaveNet-SF（97.79%）、MSLI-Net（97.50%）等基线与同类方法。
- **泛化结果（OCT2017）**：无微调直接迁移达到 99.60% 准确率，优于 Swin_Tiny（99.20%）、WaveNet-SF（99.50%）、ResNet-50（99.50%）。
- **鲁棒性**：在 26.22 dB 极端噪声下仍维持 97.79% 准确率，超越无噪声 ResNet-50（97.75%），且全面优于 Swin_Tiny（97.00%）、ConvNeXtV2（95.61%）等。
- **效率对比**：MCLM 内 MDF 模块以 33.57M 参数、6.58 GFLOPs 达到与 ASPP（142.63M 参数、27.14 GFLOPs）相同的 98.25% 精度，参数量减少 76.5%，FLOPs 降低约 75.7%。
- **消融结论**：ResNet-50 基线 97.61% → +DWT 97.79% → +MCLM 98.14% → 完整模型 98.25%；AG-HRNet 与 FAMP 在难分类（CNV vs Drusen）上显著降低误判，临床价值高于单纯平均精度提升。

## 相关工作脉络
- **WaveNet-SF / MSLI-Net**：同样利用 DWT 进行空间-频率解耦，但仅采用标准卷积处理高频分支并通过简单相加/拼接融合多尺度特征，未引入噪声感知的门控机制；本文通过 AG-HRNet 的 AGF 门控与 FAMP 的频带自适应权重，解决其高频流噪声敏感与局部细节丢失问题。
- **HRNet 及其变体（FPN-ResNet50/FPN-DenseNet121）**：多尺度并行结构有利于保留细节，但跨分支融合依赖逐元素相加，背景散斑会污染高分支；本文以 AGF 门控替换相加操作，使特征传播具备选择性。
- **HTC-Retina / SViT / Swin-Poly Transformer**：CNN-Transformer 混合架构以自注意力扩展感受野，但二次复杂度与 patch embedding 对噪声脆弱性限制了其在高分辨率 OCT 上的鲁棒性；本文采用线性复杂度的 Mamba 作为长程依赖建模核心，并通过频带门控避免全局平滑。
- **SE / CBAM / Coordinate Attention**：通用注意力机制在 OCT 散斑场景下存在空间注意力漂移或通道注意力忽略空间分布的局限；本文 MSW_SA 在小波域内生成空间注意力，内置频域降噪能力。
- **Vision Mamba / VMamba / MRVM**：将 Mamba 引入视觉与眼底图像分析，但以图像扁平化为 1D 序列为主；本文面向高频细节的子带序列建模，引入频带自适应重加权，更贴合 OCT 的局部纹理诊断需求。
- **ResNet-EdgeEn**：针对边界敏感性设计的骨干改进；本文则在双分支架构层面解决边界与纹理同时被散斑干扰的问题。

## 局限性与未来方向
- **仅在单一公开数据集（OCT-C8）与小型外部集（OCT2017）上验证**，未在多中心、多设备厂商的大规模临床数据上开展全面外部验证，泛化边界有待进一步确认。
- **DWT 仅做单层分解**，未探索多级小波分解或多小波基的适用性，可能对更深层次的结构-纹理分离存在优化空间。
- **FAMP 中 SE 式通道门控将特征硬分为低频/高频两路**，信息割裂可能损失两频带间的细粒度交叉依赖。
- **模型推理速度与时延未在文中系统评估**，AG-HRNet 多分支并行与 Mamba 序列处理联合部署时的实时性尚不明确。
- **临床转化层面**：未涉及模型解释性在医生工作流中的接受度评估、与现有 PACS 系统的集成对接，以及 prospective 临床试验验证。

## 研究启发与可借鉴点
- **空间-频率双路径解耦思路可直接迁移**至其他存在显著散斑/椒盐噪声的医学成像模态（如超声、合成孔径雷达 SAR、激光共聚焦显微镜），配合相应频带自适应模块可复用。
- **AGF 门控融合策略**（以 sigmoid 门控替代逐元素相加）可作为通用组件嵌入任意多尺度网络（如 U-Net、DeepLab、FPN）的跨层连接中，用于抑制低支噪声向高分支污染。
- **渐进式噪声注入训练策略**（三阶段由低到高、逐步提高注入概率与方差）值得在低质量临床图像分析任务中推广，能有效提升模型在真实分布偏移下的韧性。
- **FAMP 的"频带门控 + 序列建模 + 自适应重加权"范式**可与其它选择性状态空间模型（如 Mamba-2、SSD）结合，探索在病理边界追踪、微小病灶分割等下游任务上的适配。
- **MDF 以较低成本等效替代 ASPP**的设计思路：在需要扩大感受野但资源受限的场景（如嵌入式超声设备、移动端眼底筛查），可优先采用多分支空洞卷积+轻量级注意力组合。

## 关键术语表
- **Discrete Wavelet Transform (DWT)**：将图像在空间域按不同方向分解为低频近似分量与高频细节分量（水平/垂直/对角），实现结构与纹理的频域分离。
- **State Space Model (Mamba)**：基于选择性状态空间的序列建模架构，以线性时间复杂度捕获长程依赖，适用于高分辨率视觉任务的高效全局上下文学习。
- **Multi-scale Contextual Localization Module (MCLM)**：本文低频流核心模块，由多尺度空洞融合（MDF）与小波空间注意力（MSW_SA）级联构成，兼顾大范围上下文与病灶定位。
- **Attention-Guided High-Resolution Network (AG-HRNet)**：在 HRNet 多尺度并行分支基础上，以 sigmoid 门控融合（AGF）替代传统相加，抑制跨尺度噪声传播。
- **Frequency-Adaptive Mamba Projector (FAMP)**：高频流核心模块，通过 SE 式通道门控将特征拆分为低/高频路径，由 Mamba 建模长程依赖后输出自适应权重对两路径重加权融合。
- **Speckle Noise（散斑噪声）**：OCT 成像中由相干光后向散射引起的乘性噪声，表现为图像中的颗粒状伪影，会掩盖微观组织结构与病变边缘。
- **OCT-C8 / OCT2017**：OCT-C8 为 8 类共 24,000 张视网膜 OCT 图像公开数据集；OCT2017 为 4 类各 250 张的外部测试集，常用于跨数据集泛化验证。
- **Grad-CAM / LayerCAM**：基于梯度的类激活可视化方法，用于定位网络决策所关注的图像区域；本文用以说明双流架构在病灶边界的聚焦优势。
