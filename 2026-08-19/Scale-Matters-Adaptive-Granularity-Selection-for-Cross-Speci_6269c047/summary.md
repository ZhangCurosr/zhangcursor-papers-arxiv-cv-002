# 论文速读：Scale-Matters-Adaptive-Granularity-Selection-for-Cross-Speci

## 一句话总结
论文提出 AGS-PlantSeg，一种结合冻结的 Utonia 3D 基础模型与自适应粒度选择（Adaptive Granularity Selection, AGS）模块的少样本植物器官分割方法，通过为每株植物动态筛选最优特征尺度，显著提升了跨物种、跨生长阶段的 3D 点云分割泛化能力。

## 研究问题与动机
1. **固定粒度限制跨物种泛化**：3D 植物表型分析中，器官形态、尺寸密度与空间排布在物种、生长阶段及采集设置间差异巨大，单一固定空间粒度无法同时适配所有植物结构。
2. **基础模型的尺度利用不足**：Utonia 等 3D 基础模型虽支持可控粒度特征提取，但现有应用多依赖人工预设固定尺度，未能针对植物形态多样性进行自适应优化。
3. **茎-叶交界处的特征歧义**：器官过渡区域包含混合几何/语义信息，直接对所有点计算原型会偏移真实分布，导致粒度评估失真。
4. **标注数据稀缺与重训成本高**：传统专用分割网络需大量标注且难以直接迁移到新物种，亟需一种仅用少量标注即可快速适配的通用框架。

## 核心贡献（创新点）
1. **提出 AGS-PlantSeg 框架**：冻结 Utonia 编码器，仅训练轻量 MLP 分割头，实现无需全量微调的少样本 3D 植物器官分割。
2. **设计原型驱动的粒度评分策略**：构建类间分离度、类内紧凑性与边界一致性三项度量，在训练与推理阶段均能自动筛选最优粒度集合。
3. **实现跨物种稳健泛化**：在 PLANesT-3D、Pheno4D 与 Crops3D 上验证，自适应粒度平均 mIoU 达 88.9%，较最佳固定粒度基线提升 2.5 个点，且少样本性能逼近全监督专用架构。
4. **引入边界过滤原型与置信度加权融合**：剔除交界混合点后构建类别原型，并结合各粒度预测置信度进行加权决策，有效缓解形态变异带来的特征漂移。

## 方法详解
1. **基础特征提取与粒度搜索**：冻结 Utonia 编码器，将坐标归一化后的尺度变换参数作为粒度 $g$，在 $[1.0, 12.0]$ 范围内以 0.5 为步长初始化搜索（起点 4.0），为每个点生成多尺度特征向量 $f_i^g$。
2. **边界过滤原型构建**：采用 KNN（$k=1000$）识别边界点（邻近点含不同语义类别），剔除后仅用内部点计算各类别原型 $p_c^g = \text{mean}(f_i^g)$，避免茎-叶交界混合特征干扰原型中心。
3. **训练期粒度选择**：
   - 类间距离：$D_{\text{inter}}^g = \frac{1}{|\mathcal{P}|} \sum d_{\cos}(p_c^g, p_{c'}^g)$
   - 类内距离：$D_{\text{intra}}^g = \frac{1}{|\mathcal{C}|} \sum \frac{1}{|\mathcal{T}_c|} \sum d_{\cos}(f_i^g, p_c^g)$
   - 可分性评分：$S_{\text{disc}}^g = D_{\text{inter}}^g / (D_{\text{intra}}^g + \epsilon)$
   - 边界一致性评分：$S_{\text{boundary}}^{g,c} = 1 - \frac{1}{|\mathcal{B}_c|} \sum_{i \in \mathcal{B}_c} d_{\cos}(f_i^g, p_c^g)$
   - 对三个评分分别取 Top-1，合并得到训练最优粒度集合 $G_{\text{train}}^*$。
4. **轻量分割头训练**：将 $G_{\text{train}}^*$ 对应的点级特征输入两阶 MLP（隐藏层 256 维），以交叉熵损失训练，不更新 Utonia 参数。
5. **推理期粒度选择**：利用训练期存储的原型字典 $\mathcal{D}$，先用当前粒度 MLP 预测标签 $\hat{y}_i^g$，再计算预测内部点与边界点相对于字典原型的最近匹配相似度，导出 $S_{\text{interior}}^g$ 与 $S_{\text{boundary}}^{g,c}$，选出推理粒度集合 $G_{\text{inf}}^*$。
6. **置信度加权预测**：对每个点在所有选中粒度上的 MLP 概率分布按 softmax 最大置信度加权求和，取 $\hat{y}_i = \arg\max_c \sum_{g \in G_{\text{inf}}^*} w_{i,g} p_{i,g,c}$ 作为最终类别。
