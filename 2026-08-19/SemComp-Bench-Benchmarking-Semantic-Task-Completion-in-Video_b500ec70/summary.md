# 论文速读：SemComp-Bench-Benchmarking-Semantic-Task-Completion-in-Video

## 一句话总结
论文形式化了“语义任务完成视频生成”这一结果导向任务，并构建了首个联合评估视频生成模型“结果实现能力”与“生成可靠性”的基准测试 SemComp-Bench。实验表明，现有模型在保持参考图高层语义锚定的同时完成任务目标仍极具挑战。

## 研究问题与动机
- 现有视频生成基准主要关注视觉保真度、时间连贯性、主体一致性或物理常识，但缺乏对**“结果实现”与“高层语义锚定”联合能力**的系统评估。
- 实际应用（如“将钞票折成乌龟”）中，用户更关心最终生成的视频是否呈现了符合指令且与参考图像相关语义对应的结果，而非中间过程的完整性或像素级外观一致性。
- 当前开放/闭源模型在此类涉及对象交互、状态变化的复杂任务上的表现缺乏可解释的诊断性评测体系。
- 需要一个可扩展、低成本、从真实世界视频数据中自动构建的结构化评估数据集，以支撑该任务的量化研究与模型迭代。

## 核心贡献（创新点）
1. **形式化“语义任务完成视频生成”新任务**：强调结果导向，成功需同时满足预期结果的实现与对参考图像任务相关语义的保持，无需呈现完整中间步骤，允许无关属性变化。
2. **构建 SemComp-Data 数据集**：提出可扩展的四阶段流水线，将原始视频自动转化为包含参考图像、配对简短/详细指令及结果中心视频片段的三元组，确保任务真实性与细粒度对齐。
3. **提出 SemComp-Bench 评估协议**：设计基于视觉语言模型（VLM）的结构化二元问答评测框架，通过可解释的证据支撑判断，分别量化“结果实现（OA）”与“生成可靠性（GR）”两个互补维度。
4. **系统性基线评测与深入分析**：对七款代表性开源/闭源视频生成模型进行评估，揭示其在语义任务完成上的瓶颈（如实体一致性与场景连贯性），并分析条件模态（I2V vs T2V）与指令细化程度的影响。

## 方法详解
**1. SemComp-Data 构建流水线（四阶段）**
- **阶段1：候选过滤**：从 Koala-36M 数据集出发，基于标题关键词过滤掉依赖解说、非视觉自包含的视频（如新闻、访谈）。使用 VLM 对视频抽象图像进行分类，保留属于六大领域（艺术、美容时尚、手工DIY、食品烹饪、园艺宠物、运动健身）的视频。
- **阶段2：状态挖掘**：基于各领域预先定义的任务状态规范，利用 VLM 进行**帧级时间戳定位**，找到最能代表参考状态和结果状态的帧。随后通过**QA式质量检查**验证参考-结果帧对的有效性（VLM 能否明确区分哪一帧是结果帧），保守丢弃模糊对。
- **阶段3：视频扩展**：以验证后的结果帧时间戳为锚点，借鉴 Panda-70M 的分镜检测方法，提取包含结果帧的核心片段，并合并视觉一致的邻近片段，确保最终片段平均时长约 4.03 秒，聚焦于结果呈现。
- **阶段4：指令结构化**：生成**配对指令**（简短指令 i^brief + 详细指令 i^detailed）。简短指令受限于30词以内，遵循模板 `[动词] + [参考图中的主体] + [介词] + [结果视频中的主体状态]`。同时，VLM 识别并选择四种对齐类型之一（物体元素、人物身份、物体外观、场景），并确定需保留/丢弃的参考属性，以此扩展生成详细指令，明确任务完成的约束与细节。

**2. SemComp-Bench 评估协议**
- **评估基础**：从生成的视频中均匀采样 27 帧，按时间顺序输入 VLM（本文使用 Doubao-Seed-1.8）。
- **结果实现维度（OA）**：包含四个二元判定准则：
    - $A_{or}$ (Outcome Realization)：视频是否视觉上达到了指令描述的完成状态（粗粒度语义）。
    - $A_{sg}$ (Semantic Grounding)：实现的结果是否保持/修改了与参考图像-指令对相关的实体和属性。
    - $A_{gec}$ (Grounded Entity Consistency)：任务相关的关键实体在整个视频序列中是否保持语义可识别，有无无故消失、替换或漂移。
    - $A_{gvc}$ (Global Visual Continuity)：视频序列中是否存在突兀的场景、视角、布局或背景全局切换。
    - **OA Score** = $\frac{1}{N} \sum_{i=1}^{N} (a_{or}^i \cdot a_{sg}^i \cdot a_{gec}^i \cdot a_{gvc}^i)$，四项均通过才算样本通过。
- **生成可靠性维度（GR）**：独立于任务完成和语义锚定，包含五个二元判定准则：
    - $G_{pp}$ (Physical Plausibility)：动作、交互、材料行为是否符合基本物理原则。
    - $G_{vc}$ (Visual Clarity)：内容是否因模糊、曝光不当等难以识别。
    - $G_{afw}$ (Artifact-Free Rendering)：是否存在场景不一致的合成伪影（噪点、空白、色带）。
    - $G_{wsc}$ (Within-Scene Spatiotemporal Coherence)：连续场景内是否存在局部渲染不稳定（闪烁、瞬态重复、几何变形）。
    - $G_{ti}$ (Text & Interface Integrity)：文本、数字、图标、界面元素是否损坏或无法识别。
    - **GR Score** = $\frac{1}{N} \sum_{i=1}^{N} \frac{1}{5} \sum_{c \in \{pp, vc, afr, wsc, ti\}} g_c^i$，五项的平均值。
- VLM 需为每个判定提供视觉证据，提高评估可解释性。

## 实验与结果
- **数据集**：共构建 1,273 个 SemComp-Data 实例，选取其中 60 个构成领域平衡的子集 SemComp-Core（每领域 10 个）用于主要评测。
- **评测模型**：Seedance 2.0, Wan2.2-TI2V-5B, Wan2.2-I2V-A14B, CogVideoX1.5-5B-I2V, SkyReels-V2-I2V-14B-720P, HY-1.5-720P-I2V (HunyuanVideo), Phantom-1.3B。
- **结果**：
    - **最佳 OA Score**：HunyuanVideo-1.5-720P-I2V 达到 **37.8%**，其次为 Wan2.2-I2V-A14B (28.3%)。整体最高分低于 40%，表明任务极具挑战性。
    - **最佳 GR Score**：Seedance 2.0 达到 **91.8%**，Wan2.2-I2V-A14B 为 89.0%。
    - **关键发现**：
        1. **I2V 条件优于 T2V**：在所有模型族中，I2V 变体在详细指令下的 OA Score 显著高于 T2V 变体，证明参考图像对保持实体身份、外观和结构一致性至关重要。
        2. **详细指令 vs 简短指令**：详细指令在结果实现和语义锚定上更好，但简短指令在实体一致性和全局视觉连续性上表现更佳（因约束更少），揭示了任务难度与指令特异性之间的权衡。
        3. **主要瓶颈**：`Grounded Entity Consistency` ($A_{gec}$) 和 `Within-Scene Spatiotemporal Coherence` ($G_{wsc}$) 是普遍的薄弱环节。
        4. **OA 与 GR 不必然正相关**：如 Seedance 2.0 GR 最高但 OA 较低，而 HunyuanVideo OA 最高但 GR 中等。

## 相关工作脉络
- **视频生成基准**：如 VBench/VBench++、EvalCrafter、TC-Bench 等，主要评估视觉质量、时间连贯性、提示遵循，缺乏对“结果实现+语义锚定”的联合评估。
- **物理常识/世界模型基准**：如 WorldModelBench、WorldOlympiad、LikePhys、Rise-Video 等，关注物理合理性或因果/常识一致性，而非特定任务的状态转换结果。
- **个性化/可控视频基准**：如 OpenS2V-Nexus、VMBench 等，侧重主体身份保持或运动控制，未定义以结果为中心的任务完成评估。
- **视频生成模型**：Wan2.2、CogVideoX、HunyuanVideo、Seedance、SkyReels、Phantom 等，本文系统评测了它们在新兴语义任务完成基准上的表现，揭示了当前模型能力边界。

## 局限性与未来方向
- **评估依赖性**：SemComp-Bench 高度依赖所用 VLM（Doubao-Seed-1.8）的判断能力、指令遵循和证据提供质量，可能存在 VLM 自身的偏差或错误。
- **数据集规模与领域**：当前 SemComp-Data (1,273实例) 和 SemComp-Core (60实例) 规模相对有限，仅覆盖六个领域，可能无法全面反映复杂多样的真实世界任务。
- **结果中心视角的局限**：方法刻意忽略中间过程，但某些任务的“过程正确性”可能隐含在结果合理性中，当前评估无法捕捉。
- **未来方向**：
    1. 扩展 SemComp-Data 的领域覆盖和规模，引入更多样化的任务类型。
    2. 结合动态过程评估（如中间步骤合理性），形成更全面的任务完成评测。
    3. 利用 SemComp-Data 进行下游模型微调或指令微调，验证其对提升模型语义任务完成能力的潜力（论文已提及但未实证）。
    4. 探索多 VLM 集成评估以减少单模型偏差。

## 研究启发与可借鉴点
- **数据构建流水线设计**：四阶段自动化流水线（候选过滤->状态挖掘->视频扩展->指令结构化）为解决特定任务评估数据稀缺问题提供了可复用的“真实视频->结构化评测三元组”范式，成本低且可扩展。
- **细粒度、可解释的评估协议**：将综合评分分解为多个正交的二元准则（OA/GR），并要求提供视觉证据，为模型失败诊断提供了清晰、可操作的维度划分方法，值得借鉴于其他生成任务评测。
- **配对指令（Brief/Detailed）**：同一任务实例提供不同粒度指令，可用于研究指令复杂度对生成结果的影响，设计更贴近用户实际使用习惯的评测设置。
- **结果导向的任务定义**：明确区分“过程”与“结果”的评估重点，对于定义侧重于最终状态转换的应用型视频生成任务具有启发意义。
- **跨模型对比分析视角**：同时评测开源与闭源模型，并分析 I2V/T2V 条件及指令类型的效应，为研究者提供了全面的性能定位和分析框架。

## 关键术语表
- **语义任务完成视频生成 (Semantic Task Completion Video Generation)**：本文提出的结果导向视频生成任务，要求生成视频能呈现指令描述的任务结果，并保持与参考图像的任务相关语义对应。
- **结果实现 (Outcome Achievement, OA)**：评估维度之一，衡量生成视频是否成功呈现了符合指令的预期结果，并保持了参考图像的语义锚定。
- **生成可靠性 (Generation Reliability, GR)**：评估维度之一，独立衡量生成视频的物理合理性、视觉清晰度、伪影、时序连贯性及文本完整性。
- **语义锚定 (Semantic Grounding)**：指生成结果与参考图像之间在任务相关语义（如实体身份、外观、结构、场景）上的对应关系保持。
- **SemComp-Data**：本文构建的大规模评估数据集，由参考图像、配对指令（简短/详细）和结果中心视频片段构成的结构化三元组。
- **SemComp-Bench**：基于 SemComp-Data 的评估基准协议，使用 VLM 进行结构化二元问答，输出 OA Score 和 GR Score。
- **对齐类型 (Alignment Type)**：指令结构化阶段确定的参考-结果语义关联类型，包括物体元素、人物身份、物体外观、场景四类。
- **VLM (Vision-Language Model)**：视觉语言模型，本文同时用于数据构建（分类、定位、指令生成）和结果评估（判定、证据提供）。

## 可复现要素
- **数据集**：SemComp-Data（1,273 实例）可从论文附录和补充材料获取元数据、源视频 URL 和时间戳；项目页面：https://SemComp-Bench.github.io。
- **代码**：完整流水线和各阶段提示词在补充材料的 "Code" 文件夹中提供。
- **权重/模型**：评测的开源模型（Wan2.2, CogVideoX, SkyReels, Phantom 等）需从其官方渠道获取；闭源模型通过 API 调用。
- **关键超参**：采样帧数 27 帧；评估视频分辨率 720p；片段时长约 4 秒（范围 3-4s）；VLM 使用 Doubao-Seed-1.8 via Volcano Engine API；每次评估进行 3 次独立运行取平均。论文未提及其他如扩散步数、CFG 等生成侧超参，因使用模型官方默认配置。
