# 论文速读：X-LMC-Cross-View-Spatiotemporal-Collateral-Circulation-Scori

## 一句话总结
本文提出了 X-LMC，首个基于双平面数字减影血管造影（DSA）的自动化软脑膜侧支循环评分框架，通过跨视图注意力与双向时序建模，直接从对比剂动力学序列中预测 ASITN/SIR 等级，性能与人类观察者间一致性相当。

## 研究问题与动机
- 临床侧支循环评估依赖人工阅读 DSA，ASITN/SIR 评分观察者间一致性低（κ≈0.16–0.27），难以支撑可重复的大规模队列研究。
- 现有自动化侧支评分多基于 CTA/CTP 等间接模态，空间分辨率有限，无法直接利用 DSA 的高分辨率动态血管影像。
- DSA 深度学习研究多集中于血管分割、血栓检测或再灌注 TICI 评分，缺乏针对侧支循环本身的直接自动评分方法。
- 双平面 DSA 的前后位（AP）与侧位（Lat）投影携带互补的解剖与血流动力学信息，现有方法尚未有效融合跨视角时序动态。

## 核心贡献（创新点）
1. **首个 DSA 侧支循环自动评分框架**：直接从原始双平面 DSA 序列输出 ASITN/SIR 等级，填补了该任务的空白。
2. **Token 级双向跨视图注意力（X-Attn）**：在每帧 token 层面动态交换 AP 与 Lat 投影信息，区别于以往单一投影或简单特征拼接方法。
3. **冻结 DINOv2 ViT-B/14 作为稳定空间编码器**：在有限数据下提供高质量视觉表示，避免了从头训练的过拟合风险。
4. **时空联合建模对比剂动力学**：结合双向 GRU 与混合损失（CE+MAE），同时捕捉空间解剖范围与时间灌注进程。
5. **建立可复现的 benchmark 并与人类一致性对照**：首次在临床异质性标签上评估，揭示任务的主观性上限，为后续研究奠定基础。

## 方法详解
- **整体架构**：双流并行分支分别处理 AP 和 Lat 时间序列，经跨视图注意力融合后，输入双向 GRU 进行时序建模，最后通过 MLP 分类器预测 ASITN/SIR 等级（0–4）。
- **空间编码**：每帧输入冻结的 DINOv2 ViT-B/14，输出 token 级表示 \(Z_t^{(v)} \in \mathbb{R}^{N \times D}\)，\(N\) 为 token 数（含 class token），\(D=768\)。
- **跨视图融合**：对每个时间点 \(t\)，计算双向交叉注意力：
  \[
  \widetilde{Z}_t^{(\mathrm{AP})} = \mathrm{X\text{-}Attn}(Z_t^{(\mathrm{AP})}, Z_t^{(\mathrm{Lat})}), \quad
  \widetilde{Z}_t^{(\mathrm{Lat})} = \mathrm{X\text{-}Attn}(Z_t^{(\mathrm{Lat})}, Z_t^{(\mathrm{AP})})
  \]
  取更新的 class token 相加得到融合表示 \(h_t = \widetilde{z}_{t,0}^{(\mathrm{AP})} + \widetilde{z}_{t,0}^{(\mathrm{Lat})} \in \mathbb{R}^{D}\)。
- **时序建模**：将序列 \(\mathcal{H}=\{h_1,\dots,h_T\}\) 输入单层双向 GRU（隐藏维度 256），拼接正向最终状态与反向初始状态得到 \(h_{\mathrm{seq}} = [\overrightarrow{h}_T \| \overleftarrow{h}_1] \in \mathbb{R}^{512}\)，经 MLP 输出类别概率。
- **损失函数**：采用混合损失 \(\mathcal{L} = (1-\alpha)\mathcal{L}_{\mathrm{CE}} + \alpha \mathcal{L}_{\mathrm{MAE}}\)，其中 \(\alpha=0.3\)，\(\mathcal{L}_{\mathrm{MAE}}\) 为预测概率与真实标签间的平均绝对误差，以利用序数信息。
- **训练设置**：数据增强包括水平翻转、随机位移、缩放、旋转与对比度扰动；Adam 优化，批量大小 1，最多 1000 轮，早停；输入尺寸 224×224，时间序列截断至 30 帧（2 帧/秒）。

## 实验与结果
- **数据集**：多中心 MAGIC 存储库，134 例 M1 段大脑中动脉闭塞患者，由介入神经放射学医师标注 ASITN/SIR 等级（0–4，等级 0 与 1 合并）。
- **基线**：均值猜测基线；改编自 DeepTICI 的时空基线（双分支 + 1×1 卷积融合 + 单向 GRU）。
- **评估指标**：多分类用 QWK、ACC_±1、MAE；二分类（良好 vs 较差）用 Kappa 与 macro-F1。
- **主要结果**：
  - 多分类：X-LMC 取得最高 QWK=0.398（基线 0.322），ACC_±1=84.33%（基线 76.12%），MAE=0.746（基线 0.866）。
  - 二分类：X-LMC 取得最高 Kappa=0.430（基线 0.327），mF1=0.711（基线 0.663）。
  - 人类观察者间一致性 QWK=0.314，模型性能与之相当。
- **消融实验**：固定 Bi-GRU 时，X-Attn 较 Concat 在 QWK 与 Kappa 上分别提升 8.0% 与 19.3%；静态编码器中 DINOv2-ViT-B（冻结）优于 EfficientNet 变体（微调）。

## 相关工作脉络
1. **DeepTICI (Nielsen et al., 2021)**：针对 TICI 再灌注评分的时空网络，使用单向 GRU 与伪灌注监督；本文借鉴其双分支结构，但聚焦侧支循环评分，并引入跨视图注意力与双向 GRU。
2. **CVFSNet (Xu et al., 2025)**：用于 MTICI 评分的跨视图融合网络；本文同样采用跨视图注意力，但作用于 DSA 时序数据而非单帧图像。
3. **CAVE/DIAS (Liu et al., 2024; Su et al., 2024)**：DSA 血管分割与动静脉分割任务；本文不同在于直接输出临床评分，而非像素级分割。
4. **CTA/CTP 侧支评分研究 (Su et al., 2020; Potreck et al., 2022)**：基于间接模态的自动评分；本文首次直接处理高分辨率 DSA 动态序列，提供更准确的评估。
5. **人类观察者一致性研究 (Hassen et al., 2019)**：报告 ASITN/SIR 评分 κ=0.16–0.27；本文将模型性能与之对照，揭示任务的主观性上限。

## 局限性与未来方向
- **局限性**：训练仅使用单一专家参考标签，未采用多 observer 共识标注；队列局限于 M1 段闭塞，外推至其他血管床有限；数据量较小（134 例），可能限制泛化能力。
- **未来方向**：拓展至多血管床病变与更大规模队列；采用多中心共识标注以提高标签可靠性；外部验证与临床部署；探索跨模态标签传播至 CTA/CTP。

## 研究启发与可借鉴点
1. **跨视图注意力在双平面医学影像中的有效性**：可迁移至其他需要多视角融合的血管分析任务，如狭窄程度评估、动脉瘤分割。
2. **冻结预训练 ViT backbone 结合轻量时序模块的小数据策略**：适用于数据稀缺的专科医学影像任务，平衡模型容量与过拟合风险。
3. **混合损失（CE+MAE）利用序数关系**：可推广至其他有序分类任务，如疾病分期、临床评分系统。
4. **将模型性能与人类观察者间一致性对照**：为自动化诊断工具提供合理的性能天花板基准，避免过度追求超越人类。
5. **首次建立 DSA 侧支循环自动评分 benchmark**：为后续研究提供可复现的实验设置与评价标准，促进领域发展。

## 关键术语表
- **ASITN/SIR 量表**：美国介入与治疗神经放射学会/介入放射学会制定的侧支循环分级标准，0–4 级反映缺血区反流对比剂的完整性与速度。
- **双平面 DSA**：同时获取前后位（AP）与侧位（Lat）两组投影的数字化减影血管造影，提供正交视角的血管动态信息。
- **DINOv2**：基于自监督学习的 Vision Transformer 视觉编码器，无需标签即可学习鲁棒的视觉特征表示。
- **跨视图注意力（X-Attn）**：在 token 层面让不同视角的特征序列相互查询、键值更新，实现互补信息的动态融合。
- **双向 GRU**：同时考虑时间序列前后文信息的双向门控循环单元，用于建模对比剂灌流的时序动力学。
- **Quadratic Weighted Kappa (QWK)**：考虑类别顺序的加权一致性系数，权重与类别距离平方成正比，适用于有序分类任务评估。
