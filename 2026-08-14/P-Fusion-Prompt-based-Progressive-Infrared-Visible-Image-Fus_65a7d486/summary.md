# 论文速读：P²Fusion: Prompt-based Progressive Infrared-Visible Image Fusion via Dual-Prior Distillation

## 一句话总结
本文提出了 P²Fusion，一种基于"教即融合（Teach-to-Fuse）"范式的红外-可见光图像融合框架，通过蒸馏红外热显著性和可见光空间质量两种内生提示来动态引导融合过程，并结合门控动态专家重校准模块实现自适应特征解耦与融合。

## 研究问题与动机
- **硬约束先验导致优化冲突**：现有显式模态先验方法将分割掩码/显著图作为静态正则项强制约束网络，迫使模型优先拟合先验分布而非像素级特征融合，牺牲细节纹理。
- **下游任务联合优化的多目标冲突**：将目标检测或分割作为辅助任务联合优化时，任务级精度追求会损害背景细节保持，视觉美感与任务性能存在持续权衡。
- **外部语义先验的粒度失配**：基于 CLIP/DINO 等大型基础模型的外部语义引导偏离了模态本质，抽象高层表征与像素级任务存在粒度不匹配，无法有效指导低层纹理重建。
- **红外-可见光信息差异的深度融合挑战**：红外模态擅长热辐射轮廓感知，可见光模态富含纹理细节，如何在无监督条件下平衡两者、避免模态坍缩是关键难题。

## 核心贡献（创新点）
1. **"Teach-to-Fuse"范式**：提出将静态先验转化为动态可学习提示的过程导向引导框架，区别于传统硬约束和外部大模型语义引导，聚焦挖掘模态内生属性。
2. **双教师提示蒸馏机制**：设计红外热显著性教师（基于 SegFormer-B2 提取）和可见光质量教师（基于 BRISQUE 评估器），分别蒸馏空间显著性和全局质量先验作为可学习 regulator。
3. **门控动态专家重校准（GDER）模块**：提出基于 MoE 的自校正机制，将先验感知的模态专家与全局感知的注意力专家结合，通过可靠性门控自适应调节特征融合策略，实现冲突特征的解耦与修正。
4. **全面的跨基准验证与下游感知增强**：在五个主流数据集上达到 SOTA，并在 14/20 关键指标上领先；在目标检测和语义分割下游任务中显著提升鲁棒性（如 MSRS 检测 mAP +3.2%）。

## 方法详解

### 3.1 双教师提示蒸馏（Dual-Teacher Prompt Distillation）
- **红外显著性先验（T_ir）**：使用在 MSRS 和 FMB 数据集上预训练的 SegFormer-B2 作为红外显著性教师（IST），将行人和车辆定义为前景，其余为背景，生成交叉熵监督的二值显著性掩码，经双线性插值下采样后生成空间提示 P_ir。
- **可见光质量先验（T_vis）**：使用基于 BRISQUE 评估器的无参考可见光质量教师（VQT），输出图像级质量评分 s ∈ [0, 100]，归一化为连续质量先验 T_vis = (100 - s) / 100，映射为标量提示 P_vis' 匹配教师输出。
- 最终增强特征通过逐元素相加融合：F_m = f_m + Embed(P_m)，其中 m ∈ {vis, ir}。

### 3.2 自适应融合与 GDER 精化
- **交叉注意力（CA）特征调制**：
  F_ir' = CA(F_ir, F_vis, F_vis), F_vis' = CA(F_vis, F_ir, F_ir)，实现跨模态交互。
- **GDER 模块双专家架构**：
  - **先验响应模态专家（E_mod）**：显式消费动态提示，强化模态特定显著信息（热目标或高对比度纹理）。
  - **先验无关注意力专家（E_att）**：独立于提示，利用 CBAM 全局注意力机制挖掘长程依赖和细粒度结构细节，作为上下文补偿。
- **门控网络动态权重分配**：
  w = softmax(G(F', P))，精炼特征公式：F'' = F' + w_1·E_mod(F') + w_2·E_att(F')
- 经 N 次迭代精化后，双模态特征拼接送入重建解码器生成最终融合图像 I_fused。

### 3.3 优化目标
总损失由感知约束和蒸馏项组成：
- **梯度损失**：L_grad = ||∇I_fused - max(|∇I_ir|, |∇I_vis|)||_1，确保边缘保持
- **强度损失**：L_int = ||I_fused - max(I_ir, I_vis)||_1，平衡热与纹理信息
- **SSIM 损失**：L_ssim = 1 - (ω_ir·SSIM(I_ir, I_fused) + ω_vis·SSIM(I_vis, I_fused))，结构一致性（ω 基于均值梯度自适应计算）
- **可见光提示蒸馏损失**：L_vis^distill = ||P_vis' - T_vis||_2²（MSE）
- **红外提示蒸馏损失**：L_ir^distill = -(T_ir ⊙ log P_ir^map + (1-T_ir) ⊙ log(1-P_ir^map))（BCE）
- 总损失：L_total = λ_1·L_int + λ_2·L_ssim + λ_3·L_grad + λ_4·L_ir^distill + λ_5·L_vis^distill，最优权重 (λ_1~λ_5) = (8, 25, 20, 0.5, 5)

## 实验与结果

### 数据集与基线
- **五个基准数据集**：MSRS（361对）、M3FD（300对）、FMB（280对）、RoadScene（221对）、DroneVehicle（8980对）
- **训练集**：组合 MSRS（1083对）+ FMB（1220对），其中分割标签用于训练红外显著性教师
- **12 个 SOTA 基线**：SAGE、Dit-Fuse、MRFS、FreeFusion、FreqGAN、LutFuse、LRRNet、DDFM、TarDal、ReCoNet、TIM 等
- **评估指标**：|FQIE↑、VIF↑、Q_abf↑、MI↑（融合质量）；目标检测 mAP、语义分割 mPA/mIoU

### 主要定量结果
- **融合质量**：在 5 个数据集的 16 项指标中，P²Fusion 在 **12 项**上取得 SOTA，3 项第二
  - MSRS：|FQIE=**0.850**↑、VIF=**0.445**↑、Q_abf=**0.682**↑、MI=**3.905**↑
  - M3FD：|FQIE=**0.743**↑、VIF=**0.450**↑、Q_abf=**0.575**↑、MI=**3.434**↑
  - RoadScene：|FQIE=**0.628**↑、VIF=**0.266**↑、Q_abf=**0.527**↑、MI=**2.999**↑
- **下游目标检测**：
  - MSRS：mAP_50-95 = **0.748**（最优），较次优提升 **+3.2%**
  - M3FD：mAP_50-95 = **74.153**（最优），较次优提升 **+0.5%**
  - DroneVehicle（OOD）：mAP_50-95 = **0.604**（全部类别 SOTA），较次优提升 **+0.9%**
- **下游语义分割（FMB）**：mPA=**64.672**↑、mIoU=**57.456**↑，两项均最优

### 鲁棒性与 OOD 验证
- 在无烟雾遮挡、强曝光等挑战性场景中保持稳定性能
- DroneVehicle 数据集（严重域偏移， aerial 视角）无需微调即达到全部融合指标 SOTA 或次优，下游检测全面领先

## 相关工作脉络
1. **SAM/CLIP 等基础模型引导**：SAGE（CVPR'25）利用 SAM 语义先验通过语义持久注意力引导融合；CMFS（IJCAI'25）使用 CLIP 跨模态交互；P²Fusion 与之本质区别在于不使用外部大模型，而是从图像自身挖掘内生先验。
2. **硬约束显著图引导**：STDFusionNet（TIM'21）利用显著性检测掩码进行空间引导；P²Fusion 将此类先验转化为动态可学习提示而非静态正则。
3. **无监督深度学习融合架构**：Dit-Fuse（TPAMI'25）、FreeFusion（TPAMI'25）、DDFM（ICCV'23）、LutFuse（ICCV'25）等纯数据驱动方法依赖手工设计损失函数；P²Fusion 通过提示蒸馏引入过程导向的软引导。
4. **任务联合优化方法**：TarDal（CVPR'22）联合目标检测元特征；MRFS（CVPR'24）互促融合与分割；P²Fusion 不直接耦合下游任务损失，而是通过内生先验间接增强下游感知。
5. **MoE/专家混合架构**：传统 MoE 用于模型容量扩展（如大型语言模型）；本文 GDER 重新定位 MoE 为特征解耦与校正工具，结合先验感知与全局注意力双专家。
6. **质量感知融合**：PiaFusion（InfoFusion'22）利用光照感知先验；本文 VQT 教师直接评估可见光空间质量，提供更精确的纹理可靠性指导。

## 局限性与未来方向
- **教师模型依赖**：红外显著性教师基于 SegFormer-B2 在 MSRS/FMB 标注数据上训练，若目标类别分布变化可能影响先验质量；论文未讨论教师模型的泛化边界。
- **提示粒度限制**：可见光质量先验目前为图像级全局标量（经映射为 P_vis'），未探索空间级质量分布提示；消融实验也显示仅移除 P_vis 会导致 VIF 显著下降。
- **训练数据域局限**：主要在 MSRS 和 FMB 上训练，虽在 DroneVehicle 上做了 OOD 验证，但未覆盖更多极端场景（如雨雾、夜间低照度）。
- **计算开销未深入分析**：GDER 模块的双专家架构和交叉注意力增加了推理成本，论文未与轻量级基线（如 LUT-Fuse）进行效率对比。
- **未来方向**：可扩展到其他内生先验（深度、语义）、探索空间级质量教师设计、与其他模态（LiDAR、热成像多波段）的通用融合框架。

## 研究启发与可借鉴点
1. **"Teach-to-Fuse"范式可迁移**：将静态先验转化为动态可学习提示的思路可推广至其他多模态融合任务（如可见光-近红外、超声-CT），为无监督生成任务提供新的引导范式。
2. **GDER 模块的 MoE 重新定位**：将 MoE 从"容量扩展"转向"特征解耦校正"的设计值得借鉴，可在特征对齐、域适应等任务中复用此思想。
3. **双教师蒸馏的互补性设计**：选择两个正交的内生先验（热显著性+空间质量）而非单一先验，这种互补性策略可推广至其他需要多视角监督的任务。
4. **OOD 验证的严谨性**：论文在 DroneVehicle 上进行了严格的域偏移测试且无需微调，这种跨域泛化评估范式可作为后续工作的标准验证流程。
5. **可结合的方向**：本团队若在三维感知/多传感器融合方向有积累，可将内生提示蒸馏思想迁移至 LiDAR-RGB 融合、红外-深度融合等场景。

## 关键术语表
- **Infrared-Visible Image Fusion (IVIF)**：将红外图像的热辐射信息与可见光图像的纹理细节融合为单一高质量图像的技术。
- **Teach-to-Fuse (T2F)**：本文提出的新范式，将先验知识从静态约束转化为可学习的动态提示，通过双教师蒸馏过程引导融合。
- **Gated Dynamic Expert Recalibration (GDER)**：基于门控 MoE 的特征重校准模块，通过模态专家和注意力专家的自适应加权实现特征解耦与修正。
- **Infrared-Saliency Teacher (IST)**：基于 SegFormer-B2 的红外显著性教师模型，输出行人/车辆的空间显著性掩码作为先验。
- **Visible-Quality Teacher (VQT)**：基于 BRISQUE 评估器的无参考质量教师，输出可见光图像的全局质量评分作为空间质量先验。
- **Modality Specialist (E_mod)**：GDER 中的先验响应专家，依赖动态提示强化模态特定的显著区域。
- **Attention Specialist (E_att)**：GDER 中的先验无关专家，通过 CBAM 全局注意力捕获长程结构依赖。
- **Out-of-Distribution (OOD) Verification**：在训练域外数据（如 DroneVehicle 航拍场景）上测试模型泛化能力的评估方法。
