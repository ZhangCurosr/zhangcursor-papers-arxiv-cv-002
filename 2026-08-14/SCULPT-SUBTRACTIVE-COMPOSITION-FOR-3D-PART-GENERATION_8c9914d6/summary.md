# 论文速读：SCULPT-SUBTRACTIVE-COMPOSITION-FOR-3D-PART-GENERATION

## 一句话总结
论文提出 SCULPT 框架，将部件感知 3D 生成建模为**减法组合（subtractive composition）**：从完整对象出发，反复通过联合分割预测器同步生成一个提取部件与剩余对象，从而在保持整体几何一致性的同时实现可变数量的语义部件分解。

## 研究问题与动机
- **现有分割方法局限**：2D/3D 分割方法仅对已生成几何进行后验划分，无法同时生成部件边界两侧的几何与材质，尤其难以处理新暴露的接触面。
- **现有加法方法局限**：直接生成部件的方法（固定槽位或可变长序列）常导致部件间间隙、穿插或材质不连续，且需提前预测全部部件集合，难以适配对象依赖的部件数量。
- **变量卡inality 建模困难**：传统方法将部件数量纳入全局输出预测，导致长尾分布与终止控制难题。
- **利用整体生成先验**：现代 3D 生成器已隐式学习重复子结构（腿、轮、把手等），将分解视为生成任务而非纯识别任务，可保留生成器全程参与分解过程。

## 核心贡献（创新点）
- **减法组合形式化**：将变量部件集合的生成转化为固定签名的循环“部件–剩余”分裂操作，部件数量由 rollout 长度决定而非固定输出槽位。
- **联合分割预测器设计**：基于 TRELLIS.2 预训练权重初始化，通过 decomposition flow transformer 实现图像条件与当前剩余状态条件的耦合去噪，使部件与剩余在共享轨迹上同步生成。
- **原生支持约束机制**：引入 sparse-support composition loss、推理时支持裁剪与空剩余终止策略，保证每一步预测的部件与剩余联合覆盖当前对象支持，避免递归状态漂移。
- **端到端几何–材质联合生成**：每个部件在完整对象坐标系下解码为带纹理网格，无需单独归一化或配准即可直接组装。
- **SOTA 性能验证**：在 PartObjaverse 基准上实现部件级、语义组级与对象级 Chamfer 距离与 F1@.05 的最佳结果，同时在多场景定性实验中展现强泛化能力。

## 方法详解
- **整体流程**：给定条件图像 $\mathcal{I}$，先用预训练 TRELLIS.2 生成完整对象潜变量 $z_0$；随后循环执行 $(\hat{z}_i, z_i) = P_\theta(z_{i-1}, \mathcal{I})$，存储提取部件 $\hat{z}_i$，将剩余 $z_i$ 输入下一步，直至支持集为空或达到最大步数 $K_{\max}=24$。
- **结构化潜变量**：采用 TRELLIS.2 的三阶段有序表示 $z=(z^v, z^g, z^m)$，分别对应稀疏结构（O-Voxel 支持）、几何特征与材质特征，所有部件与剩余共享同一坐标系 $[-1,1]^3$。
- **联合预测器架构**：每个阶段 $P_\theta^s$ 包含联合去噪分支与并行剩余控制分支；联合分支初始化为 TRELLIS.2 权重，控制分支通过零初始化的残差投影注入当前剩余特征，实现渐进式适配。
- **矩形流匹配损失**：在 packed 目标 $(\hat{z}_i^s, z_i^s)$ 上训练 velocity network，优化 $\mathcal{L}_{\text{flow}}^s = \mathbb{E}[\|v_\theta^s(y_i^s(t), t, \mathcal{I}, z_{i-1}^s) - (\epsilon - y_i^s)\|^2]$。
- **稀疏组成损失**：在结构阶段，通过可微并集结算子 $u_i = 1 - (1-\hat{p}_i)\odot(1-p_i)$ 计算预测部件与剩余的概率并集，与输入支持 $\mathcal{O}_{i-1}$ 计算 BCE，加权 $\lambda_{\text{comp}}=0.1$ 加入总损失，强制联合覆盖当前对象。
- **推理时裁剪与终止**：将预测概率通过阈值 $\tau_{\text{occ}}$ 转为硬支持，并裁剪至当前剩余支持 $\hat{\mathcal{O}}_i, \mathcal{O}_i \subseteq \mathcal{O}_{i-1}$；当 $\mathcal{O}_i=\emptyset$ 或达到 $K_{\max}$ 时终止，非空裁剪剩余作为最终部件保留。

## 实验与结果
- **数据集**：训练使用 PartVerse-XL（37,425 对象、330,455 监督分裂对），评估使用 PartObjaverse（200 个带部件标注的 mesh，与训练集无标签泄露）。
- **基线**：直接部件生成类（Part123、OmniPart）与后验分割类（TRELLIS/TRELLIS.2 + PartField、SAM3D、HoloPart）。
- **主要结果**：SCULPT 在 PartObjaverse 三个层级均取得最优：
  - **部件级**：CD=0.0107（最佳），F1@.1=0.8858，F1@.05=0.7599（最佳）
  - **语义组级**：CD=0.0107（最佳），F1@.1=0.8851，F1@.05=0.7614（最佳）
  - **对象级**：CD=0.0020（最佳），F1@.1=0.9839（最佳），F1@.05=0.9212（最佳）
- **提升幅度**：相比最强直接生成基线 OmniPart，部件级 CD 从 0.0136 降至 0.0107（↓21%），F1@.05 从 0.7025 升至 0.7599（↑8.2%）；相比最强后验分割基线 TRELLIS.2+PartField，部件级 CD 从 0.0115 降至 0.0107（↓7.0%），F1@.05 从 0.7554 升至 0.7599。
- **定性泛化**：在四张数据集图像、一张文生图输入与一张真实照片上均能生成纹理一致的分离部件，重组后保持原始轮廓与相对位置。

## 相关工作脉络
- **整体 3D 生成**：TRELLIS、TRELLIS.2、Hunyuan3D 2.5 等预训练图像到 3D 生成器提供完整对象潜变量与几何–材质先验，本文将其作为分解起始状态而非最终输出。
- **3D 部件分割**：PartField、P3-SAM、SAMPart3D 等方法在固定资产上进行后验划分，保留几何但不生成部件边界两侧的新暴露面；本文通过联合生成机制直接合成边界几何与材质。
- **直接部件生成**：OmniPart、PartGen、UniPart 等方法通过布局规划、潜变量解耦或自回归方式生成部件集合；本文避免全局预测可变长集合，改用固定签名的递归分裂降低建模复杂度。
- **条件控制与联合生成**：ControlNet、IP-Adapter、JointDiT 等工作展示附加条件引导生成器的能力；本文将其扩展至“当前剩余状态”这一动态 3D 条件，实现部件–剩余的耦合预测。
- **定位差异**：SCULPT 核心创新在于将减法分解与 3D 扩散生成深度融合，通过显式剩余状态、共享边界体素与原生支持约束，实现几何–材质一致的递归部件合成，区别于纯分割或纯生成的独立流程。

## 局限性与未来方向
- **固定最大分裂数**：受 $K_{\max}=24$ 安全上限约束，极端复杂对象可能留有非空裁剪剩余，需校准终止信号以进一步细化粒度。
- **数据依赖**：训练依赖 PartVerse-XL 等人工标注部件 mesh，数据质量与覆盖类别影响泛化；未来可扩展至弱监督或无监督分解。
- **计算开销**：递归分裂需多次前向传播，推理速度低于单次生成方法；可通过流水线优化（如阶段重叠执行）缓解。
- **边界精确性**：共享 interface shell 允许重叠体素，虽避免硬分割，但边界几何仍需依赖网络学习；未来可引入显式界面感知损失。
- **方向拓展**：可探索直接粒度控制、物理属性分配、动画绑定等下游应用，以及与语言前端结合的交互式编辑。

## 研究启发与可借鉴点
- **递归固定签名设计**：将变量输出问题转化为固定两步预测的循环过程，可有效规避可变长序列建模的终止难题，适用于其他递归生成任务。
- **原生支持约束机制**：composition loss 与推理时裁剪相结合，保证递归状态始终约束在合法域内，可迁移至其他需要状态保持的生成任务（如层次化场景生成）。
- **共享边界体素设计**：允许部件与剩余在边界处重叠，避免 voxel-face 硬分割导致的几何断裂，对多视图融合、分层重建等有借鉴价值。
- **预训练权重适配策略**：零初始化残差投影的 ControlNet 式注入，既能保留整体生成先验，又能渐进学习减法任务，可作为微调扩散模型的通用范式。
- **三阶段有序联合预测**：结构→几何→材质的顺序处理与 packed 目标共享去噪计算，提升显存效率的同时保持多模态一致性，可复用于其他多阶段 3D 生成管线。

## 关键术语表
**Subtractive Composition（减法组合）**：从完整对象出发反复提取部件与剩余对象的生成范式，部件数量由递归步数决定。
**Joint Split Predictor（联合分割预测器）**：同时预测提取部件与更新剩余状态的神经网络，基于分解流 transformer 实现。
**Structured Latent（结构化潜变量）**：TRELLIS.2 提出的三阶段有序表示，包含稀疏结构、几何与材质潜变量。
**Sparse Support（稀疏支持）**：由 O-Voxel 网格定义的活跃体素集合，表示对象在 3D 空间中的占据区域。
**Composition Loss（组成损失）**：监督预测部件与剩余并集覆盖当前对象支持的 BCE 损失项。
**Interface Shell（界面壳）**：部件与剩余共享的重叠边界体素，避免硬分割导致的几何间隙。
**Rectified Flow Matching（整流流匹配）**：训练 velocity network 预测从干净样本到噪声的向量场的损失函数。
**Inference-time Clipping（推理时裁剪）**：将预测支持裁剪至当前剩余支持的约束策略，保证递归状态合法性。
