# 论文速读：SCULPT-SUBTRACTIVE-COMPOSITION-FOR-3D-PART-GENERATION

## 一句话总结
SCULPT 将部件感知的 3D 生成形式化为**减法组合（subtractive composition）**过程：从完整的 3D 对象隐空间出发，迭代地联合预测"一个提取部件 + 剩余对象"，用固定签名的递归分裂替代一次性预测可变数量的部件集合，在 PartObjaverse 基准上达到 SOTA，同时保持零件级几何精度与装配后整体重建质量。

---

## 研究问题与动机
- **现有部件感生成方法存在结构性缺陷**：分割类方法（如 SAMPart3D、PartField）在已生成的完整形状上贴标签，无法生成部件边界两侧的几何/材质；加法类方法（如 OmniPart、Part123）通过预设布局或 token 合成部件，但共享边界容易出现缝隙、穿插和材质不连续。
- **可变部件基数难以建模**：固定槽位方案将输出容量上限与最大部件数绑定，可变长序列方案需要学习"何时发射多少元素"，两者都在全局输出预测中处理基数问题。
- **整体生成模型隐含了子结构先验**：TRELLIS.2 等单图→3D 生成器已学会重复出现的子结构（腿、轮子、把手等）及其组合方式，但只输出不可分割的单体资产，未暴露结构部件。
- **需要一种保留生成器全程参与分解的方法**：将分解本身视为生成问题而非仅是对固定资产的识别，使每个部件与其剩余对象能在共享轨迹上联合生成。

---

## 核心贡献（创新点）
1. **提出减法组合形式化**：将可变部件基数的输出转化为递归、固定签名的部件–剩余对象分裂，部件数量由 rollout 长度决定而非固定槽位或预定义布局。与 Part123/OmniPart 等直接合成全部部件的方法本质不同。
2. **设计联合分裂预测器（joint split predictor）**：基于分解流 Transformer 块，利用零初始化残差投影的 ControlNet 风格分支注入当前 3D 剩余状态，使提取部件与更新后的剩余对象在共享轨迹上联合去噪。与 UniPart（潜分割+逐部件扩散）和 AutoPartGen（自回归无显式剩余状态约束）均不同。
3. **引入原生支持集约束机制**：包括稀疏支持组合损失（sparse-support composition loss）、推理时支持裁剪（support clipping）和空剩余终止策略，保证部件–剩余对的并集覆盖当前输入支持且 recurrent 状态始终处于被分解对象内。
4. **SOTA 定量性能**：在 PartObjaverse 上同时达到部件级、语义组级和对象级最低的 Chamfer Distance 与最高的 F1@.05，证明精细分解不会以牺牲装配完整性为代价。

## 方法详解
**总体流程**：给定条件图像 I，先用预训练图像→3D 生成器 TRELLIS.2 获得完整对象结构化隐变量 z₀；然后迭代调用联合分裂预测器 P_θ，第 i 步输入当前剩余隐变量 z_{i-1} 和图像 I，输出提取部件 ĥz_i 与更新后剩余 z_i：
- z₀ = G_φ(I)
- (ĥz_i, z_i) = P_θ(z_{i-1}, I)

**结构化 3D 隐变量**：采用 TRELLIS.2 的三阶段表示 z = (z^v, z^g, z^m)，分别对应稀疏结构（O-Voxel 支持集）、几何和材质；所有部件和剩余对象共享同一坐标系 [−1,1]³，无需额外对齐。

**分解流 Transformer 块（Decomposition Flow Transformer）**：
- 每个阶段包含联合去噪分支（从 TRELLIS.2 checkpoint 初始化）和并行的剩余控制分支（ControlNet 风格零初始化残差投影）。
- 控制分支通过公式 c_{l+1} = C_l(c_l, z_{i-1}; e_I, e_t)，联合分支通过 h_{l+1} = B_l(h_l; e_I, e_t) + Z_l(c_{l+1}) 交互更新。
- 在几何/材质阶段，部件与剩余对象的特征被放置在它们原生稀疏支持的**并集**上联合去噪，允许相邻支持重叠而非强制离散体素划分。

**训练目标**：
- 每个阶段的流匹配损失：L_flow^s = E[||v_θ^s(y_i^s(t), t, I, z_{i-1}^s) − (ε − y_i^s)||²]
- 稀疏结构阶段额外添加组合损失（composition loss）：L_comp = −(1/N³) Σ_q [O_{i-1,q} log u_{i,q} + (1−O_{i-1,q}) log(1−u_{i,q})]，其中 u_i 为预测部件与剩余对象占据概率的可微并集。总损失 L^v = L_flow^v + λ_comp·L_comp（λ_comp=0.1），L^g=L_flow^g，L^m=L_flow^m。

**推理过程**：
- 将稀疏阶段预测的概率图以阈值 τ_occ 二值化为硬支持集，并裁剪到当前剩余支持 O_{i-1} 内：Ô_i = 1[ p̂_i > τ_occ ] ∩ O_{i-1}，O_i = 1[p_i > τ_occ] ∩ O_{i-1}。
- 用裁剪后的支持集约束后续几何/材质阶段，更新后的剩余隐变量传入下一步。
- Rollout 在剩余支持为空或达到安全上限 K_max=24 时终止；若上限触及时剩余非空，则保留剩余部分作为最终输出部件之一。

**训练数据构建**：对 PartVerse-XL 中的每个带标注资产，按质心 Z-X-Y 字典序确定部件提取顺序，生成 K 个训练元组 (I, z_{i-1}; ĥz_i, z_i)，其中每个元组满足 M_{i-1} = ĥM_i ⊕ M_i（mesh 并集关系）。

## 实验与结果
- **训练数据集**：PartVerse-XL（从 Objaverse-XL 筛选），经过去重、质量控制后含 37,425 个对象、330,455 个监督部件–剩余分裂对。
- **评估基准**：PartObjaverse（200 个网格，含实例级与语义级部件标注），与训练集独立（SHA-256 去重）。
- **评估指标**：Chamfer Distance（CD↓）和 F1@0.1↑、F1@0.05↑，分部件级、语义组级、对象级三个层次。
- **最强结果**：
  - 部件级：CD=0.0107，F1@.05=0.7599（超越 OmniPart 的 0.0136/0.7025）
  - 语义组级：CD=0.0107，F1@.05=0.7614
  - 对象级：CD=0.0020，F1@.05=0.9212（超越 OmniPart 的 0.0032/0.8732）
  - 相对于最强后处理分解基线 TRELLIS.2+PartField：部件级 CD 降低 7.0%、语义组级 8.5%、对象级 4.8%
- **消融实验**：Voxel only（仅适应稀疏结构）CD 升至 0.0439；去掉组合损失 CD 升至 0.0279；去掉推理裁剪 CD 升至 0.0260，证明全阶段适应、组合监督和裁剪均不可或缺。
- **泛化验证**：在 4 张数据集图片、1 张文生图输入和 1 张真实照片上均产生保真装配对象与语义分割的 textured 部件。

## 相关工作脉络
1. **分割类方法**（SAMPart3D、PartField、P3-SAM）：在已生成资产上后验分割，保留表面几何但不生成边界两侧的新几何；SCULPT 将分解本身视为生成过程，在每个分裂步骤联合生成部件和剩余对象。
2. **直接部件生成方法**（Part123、OmniPart、PartGen）：一次性预测全部部件或从预设布局合成；SCULPT 用递归固定签名分裂替代全局输出预测，规避可变基数的建模难题。
3. **UniPart**（He et al., 2026）：同样利用整体生成先验，但分解方式为"潜分割→逐部件扩散"；SCULPT 保留显式剩余状态并通过联合去噪保持边界一致性。
4. **AutoPartGen**（Chen et al., 2025b）：自回归生成部件并自动终止，但无显式剩余状态约束且仅建模几何；SCULPT 每步都携带剩余对象状态并在原生支持并集上联合处理部件–剩余对。
5. **HoloPart**（Yang et al., 2026）：生成性 amodal 分割；SCULPT 不需要独立的补全模块，因为部件与剩余对象在同一联合去噪轨迹中自然产生互补边界。
6. **条件控制方法**（ControlNet、T2I-Adapter、JointDiT）：展示了预训练模型的附加条件注入能力；SCULPT 借鉴了 ControlNet 风格设计，将当前 3D 剩余状态以零初始化残差投影方式注入 DiT 块。

## 局限性与未来方向
- **安全上限截断**：K_max=24 为硬上限，复杂对象可能被截断而残留未分解的剩余块，需改进终止判定机制。
- **接口感知目标缺失**：当前组合损失约束并集覆盖但不显式建模部件间接触面的几何/材质连续性，作者指出 "interface-aware objectives" 是自然扩展方向。
- **颗粒度控制有限**：当前通过质心排序确定提取顺序，缺乏对细粒度/粗粒度分解的直接控制，作者建议 "direct granularity control" 作为未来工作。
- **训练数据依赖**：需要 PartVerse-XL 这类带有人工细化部件网格的数据，泛化到无标注场景受限。
- **单张图像条件的不确定性**：虽然展示了真实照片上的良好表现，但单图→3D 本身的固有模糊性可能影响部件边界的准确性。

## 研究启发与可借鉴点
1. **减法组合范式可迁移**：将可变基数输出问题转化为递归固定签名操作，这一思想可推广到其他需要分解/组合的 3D 生成任务（如场景分解、层次化装配）。
2. **联合去噪共享轨迹设计**：部件与剩余对象在原生稀疏支持并集上联合去噪，避免硬体素划分带来的边界伪影；该策略可用于任何需要保持共享边界的成对生成任务。
3. **ControlNet 风格零初始化残差注入**：从预训练主干出发、通过零初始化残差投影引入新条件，既保留先验又允许灵活扩展，是本论文的架构精华，可直接复用。
4. **组合损失的设计思路**：通过可微并集 + BCE 约束预测输出的覆盖完整性，有效防止 recurrent 状态漂移；该损失形式可应用于其他需要维持状态守恒的序列生成任务。
5. **推理时支持裁剪机制**：将预测支持裁剪到当前状态内保证了非扩张序列性质，这一安全约束可推广到任意基于状态迭代的 3D 生成 pipeline。

## 关键术语表
- **Subtractive Composition（减法组合）**：从完整对象出发反复提取一个部件并更新剩余对象，用 rollout 长度表达可变部件基数的生成范式。
- **Joint Split Predictor（联合分裂预测器）**：同时预测提取部件和更新后剩余对象的神经网络，基于 Decomposition Flow Transformer 实现。
- **Decomposition Flow Transformer（分解流 Transformer）**：含联合去噪分支和剩余控制分支的 Transformer 块，通过零初始化残差投影注入 3D 条件。
- **Structured Latent（结构化隐变量）**：TRELLIS.2 的三阶段隐表示 z=(z^v, z^g, z^m)，涵盖稀疏结构、几何和材质。
- **O-Voxel**：TRELLIS.2 使用的稀疏体素网格表示，分辨率 N³，支持集 O ∈ {0,1}^{N³}。
- **Composition Loss（组合损失）**：约束预测的部件与剩余对象的占据概率并集覆盖输入剩余支持的二元交叉熵损失。
- **Interface Shell（接口壳）**：部件与剩余对象在原生日持支持并集上重叠的边界体素层，避免硬体素面划分。
- **PartObjaverse**：基于 SAMPart3D 发布的含 200 个带实例级与语义级部件标注网格的评估基准。

## 可复现要素
- **数据集**：训练集 PartVerse-XL（37,425 对象），评估集 PartObjaverse（200 网格，来自 SAMPart3D 论文）；论文声明两部分独立标注、无标签泄漏。
- **代码开源**：项目页面 https://sculpt-part.github.io/（论文声称开源，具体代码仓库需访问该页面确认）。
- **权重开源**：split predictor 初始化权重来自公开 TRELLIS.2 checkpoint；模型页面可能有额外发布。
- **关键超参**：λ_comp=0.1，K_max=24，τ_occ（推理占用阈值，论文未明确数值），lr=10⁻⁴，AdamW（β₁=0.9, β₂=0.999, weight decay=10⁻²），800K 步，32 GPU，per-GPU batch size=1，几何/材质阶段过滤部件 token 数 <8 或 >8192 的分裂。
